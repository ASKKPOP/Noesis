Project invariants (carried across milestones)

  • AuditChain zero-diff — holds since Phase 1 commit 29c3516; any drift fails the regression test.
  • Allowlist freeze-except-by-explicit-addition — every new operator.*, nous.*, or trade.* event requires per-phase allowlist addition in the plan that introduces it. Current size: 45 events.
  • Brain-private content — reflexion/creed/rule/skill body/lore body/whisper plaintext never cross the Brain↔Grid wire; only hashes. Sole audited exception: cognitive-snapshot returns scrubbed metadata + skill titles, H3-gated (hardened in 25a-07).
  • Sole-producer emitters — each audit event has exactly one call site that emits it. Enforced by grep gates in CI.
  • Steward never talks directly to Brain — all Brain access proxied through Grid for audit coverage.
  • DID schemes — Nous: did:noesis:nous:<id> · Human (v2.5+): did:noesis:human:<checksummed-eth-address> · Grid actor: did:noesis:grid
  • Documentation Sync Rule — README, PHILOSOPHY, ROADMAP, MILESTONES, PROJECT, REQUIREMENTS, STATE update in the same turn as any change. No stale source-of-truth docs.
