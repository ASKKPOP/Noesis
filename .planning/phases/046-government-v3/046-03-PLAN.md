# Plan 03 — Routes + Doc-Sync

## Goal
Civic-DID-gated `/api/v1/gov/*` routes wired into the server, route tests GREEN, CI gates green, docs synced, committed.

## Steps
1. **grid/src/api/routes/gov.ts** — `registerGovRoutes(app, services)` (mirror `routes/irs.ts`):
   - `POST /bill/draft` — author civic-did from body; validate title/body (≤32KiB), category; compute title_hash/body_hash (sha256); `store.insertBill`; emit `gov.bill_drafted` (author hashed); 201.
   - `POST /bill/:id/cosponsor` — cosponsor civic-did; bill must exist (404); self-cosponsor (author)→422 `self_cosponsor`; dup→409 `duplicate_cosponsor`; `store.addCosponsor`→count; emit `gov.bill_cosponsored`; if count≥threshold set status `cosponsored`.
   - `POST /session/open` — `verifyGovernmentSession`→403 else; bill must be `cosponsored` (422 `bill_not_cosponsored`); `store.openSession`; emit `gov.session_opened` (speaker civic-did-hash per D-46 sourcing); status→`in_session`.
   - `POST /session/:id/argument` — civic_did required (visitor→401 handled by policy hook); session open + before deadline (422 `debate_closed`); `store.addArgument`; 201 (no audit event — arguments are Grid-side text, not chain).
   - `POST /session/close` — government_only; `store.closeSession`; outcome `advanced_to_vote|withdrawn`; emit `gov.session_closed`; if advanced, set `gov_bills.proposal_id` (links existing VOTE-05 proposal supplied in body).
   - `POST /law/enact` — government_only; requires passed proposal ref; `store.enactLaw`; emit `gov.law_enacted` (supersedes optional); 201.
   - `POST /law/:id/repeal` — government_only; `store.repealLaw`; emit `gov.law_repealed`.
   - `GET /law/active` — public; `store.getActiveLaws`; `Cache-Control: public, max-age=10`.
   - `GET /bill/:id` — public; bill metadata + body_text (visitor-readable per Phase 36).
   - **D-46 speaker civic-did trap:** never pass `did:gov:` to a hashed-as-civic producer field. Use the authenticated request's civic speaker DID, else civic placeholder `did:civic:noesis:speaker`. Document any deviation as D-46-0x.
