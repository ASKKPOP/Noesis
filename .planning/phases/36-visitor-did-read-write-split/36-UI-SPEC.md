# Phase 36 — UI Design Contract
## Visitor / DID Read-Write Split — Portal Landing + Civic Map + Library Reading Room + Marketplace Browse + Polis Bills

> Visual and interaction contract for the **five primary visitor-facing surfaces** of the v3.0 Polis (Civic City) frontend. Phase 36 is unusually heavy on UI scope because it locks the v3.0 visitor experience for an entire milestone — every surface launched after it (Phases 37-57) extends what's contracted here.
>
> **Surfaces covered (5 primary + 3 secondary):**
> 1. Portal landing page (D-36-01) — the visitor's entry URL
> 2. Civic Map (D-36-12..15) — 6-zone city with per-Nous avatars, 5s polling
> 3. Library reading room — visitor browses skills + lore (extends v2.4 Phase 20)
> 4. Marketplace browse (D-36-03) — listings with prices visible to visitors
> 5. Polis bill drafts view (D-36-15) — pending bills + sessions, ballots redacted
>
> Secondary surfaces:
> - Public Nous profile (D-36-11) — clicked from Civic Map avatar
> - Public events stream (firehose redacted per D-V3-12) — last 1000 events sliding window
> - Zone deep-dive (D-36-14) — tax rate, recent activity, top contributors
>
> **Three tiers × five surfaces** generates the differentiation matrix in §Tier Differentiation Matrix.
>
> Generated by gsd-ui-researcher. ## Typography

Four-size scale + four-weight discipline established v2.4 Phase 21 (Steward) and v2.5 Phase 24 (Portal). Phase 36 declares **4 sizes × 2 weights** as the formal typography contract.

| Role | Size | Tailwind | Weight | Line-Height | Family | Usage in Phase 36 |
|------|------|----------|--------|-------------|--------|-------------------|
| Display (editorial) | **34px** | `text-[34px]` | 400 | 1.1 | Cormorant Garamond (serif) | Portal landing hero ("Welcome to the Polis"); Civic Map zone deep-dive heading |
| Heading | **20px** | `text-xl` | 600 | 1.2 | Inter Tight | Surface card titles ("Recent Bills", "Marketplace Listings", "Library Entries"); Public Nous profile name |
| Body | **14px** | `text-sm` | 400 | 1.5 | Inter Tight | Bill body summary; listing description; library entry abstract; tier-badge labels |
| Meta / caption / mono | **12px** | `text-xs` | 400 | 1.4 | JetBrains Mono (for DIDs/ticks) or Inter Tight (for non-mono captions) | Civic Map legend; zone tax labels; bill sponsor DID hash; listing seller DID hash; "Sign up to participate" CTA byline |

**Weight discipline:** Only **400 (regular)** and **600 (semibold)**. No 500. No 700. Matches v2.4-v2.6 precedent. Cormorant Garamond uses 400 only (italic 400 reserved for redacted-field placeholders).

**Mono usage:** JetBrains Mono is reserved for `text-xs` (12px) DID strings, tick numbers, allowlist event names, hash prefixes. Body and headings always use Inter Tight or Cormorant Garamond.

**Line-height discipline:**
- `leading-tight` (1.2): Display headings, surface headings
- `leading-snug` (1.4): Mono captions
- `leading-normal` (1.5): Body copy (default)
- `leading-relaxed` (1.65): Portal landing explainer copy (Cormorant Garamond italic optional)

### Accent reserved-for list (DEFINITIVE)

The 10% accent budget is consumed by **layer-semantic accents only**. Phase 36 forbids decorative use of accent colors on:
- Interactive buttons not tied to a specific layer (use neutral `text-[#e8e8ec]` + border `border-[#2a2a34]`)
- Page-level headings (use `text-[#e8e8ec]`)
- Decorative dividers (use `border-[#2a2a34]`)
- Hover states on neutral elements (use `bg-[#1c1c24]`)

**Allowed accent uses (complete enumeration):**

1. **Portal pink (`#f472b6`)** — Portal hero "Sign Up" CTA button (filled background); Portal session "Signed in as X" badge top-right; Portal logo wordmark; "Apply for Civic-DID" CTA in Human Visitor tier.
2. **Grid orange (`#ffb86c`)** — "Genesis Grid" name badge in nav; Civic Map outer 1px frame; inline `<code>` DID strings; Marketplace surface card 4px left-border; "Browse the City" hero CTA secondary button.
3. **Polis green (`#6bd968`)** — Polis bill card 4px left-border; "Active session" pill badge on bill cards; Government Quarter zone fill on Civic Map (low-opacity 12%); tally pass-count number.
4. **Zone sky (`#38bdf8`)** — Zone deep-dive page heading; zone-jump buttons in Civic Map legend; Civic Map hovered-zone stroke; zone-tag chip on Marketplace listings.
5. **Type A blue (`#7c9eff`)** — Type A Nous avatar circle fill on Civic Map; "Local" badge on public Nous profile next to Existence-DID.
6. **Type B purple (`#c084fc`)** — Type B Nous avatar circle fill on Civic Map; "Hosted" badge on public Nous profile; tally fail-count number.

**Brand color ratio check:** Across any visitor surface, layer-semantic accents combined should occupy ≤10% of pixel area. Civic Map is exempt (zone fills are the surface — but use low-opacity 12% backgrounds, not solid).

## Destructive Actions

Phase 36 ships **zero destructive actions** for visitors. Anonymous + Human Visitor surfaces are read-only by definition (VIS-02 invariant). Civic Member affordances exposed in this phase (`Follow`, `Watch`, `Cite`, `Place bid`, `Co-sponsor draft`) are all additive write operations routed to other phases.

The one revocation-adjacent path — D-36-09 (Civic-DID revoked → revert to visitor) — is **not user-initiated**; it is a consequence of Phase 47 Police sanction execution. The visitor-side UI consequence is a friendly banner ("Your Civic-DID has been revoked. You can still browse…"), not a destructive confirmation flow.

**Confirmation contract for future phases:** When a destructive write affordance is added (e.g., Phase 44 `Cancel listing`), follow the Phase 8 `IrreversibilityDialog` pattern (verbatim-text confirmation, 2-step input match). Phase 36 establishes no precedent — it ships none.
