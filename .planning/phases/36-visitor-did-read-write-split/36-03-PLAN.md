<objective>
Extend the existing `WsFirehoseHub` (grid/src/audit/firehose-hub.ts) so each WebSocket subscriber carries a `DIDContext | null` captured at upgrade time. The wire serializer branches: `civic_member` subscribers receive the full audit entry; everyone else receives a redacted frame containing only `{tick, event_type, family}`. The audit chain itself is untouched — redaction happens at egress only. This preserves R-31-01 zero-diff: chain head hash is independent of subscriber composition.

Purpose: VIS-03 + R-31-01 invariant preservation. Plan 01 firehose-hub-redaction.test.ts and firehose-hub-zero-diff.test.ts depend on this plan to turn GREEN. Plan 05's audit-stream route depends on the WS upgrade handler reading the bearer.

Output: 1 new file (pure serializer) + 2 modified files (hub + upgrade route).
</objective>
