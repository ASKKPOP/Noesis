# Phase 26 — UI Design Contract: Sophia Onboarding

> Visual and interaction contract for the first-time user onboarding wizard at `/portal/onboard`.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — CSS variables only (portal-theme class) |
| Preset | not applicable |
| Component library | none — inline style objects, raw HTML elements |
| Icon library | inline SVG (consistent with auth page pattern) |
| Font — serif | Cormorant Garamond (var(--serif)) — Sophia voice, narration |
| Font — sans | Inter Tight (var(--sans-portal)) — UI chrome, user input |
| Font — mono | JetBrains Mono (var(--mono-portal)) — labels, metadata |

All components use the `.portal-theme` CSS class scope. No Tailwind color classes. No shadcn.
Inline `style={{ ... }}` objects with `var(--token)` references only.

---

## Color

The wizard renders full-screen over the CyberGrid dark canvas. The palette is the portal auth page
palette (dark on dark, not the light `.portal-theme` editorial palette used by the portal shell).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#020610` | Page background, behind CyberGrid canvas |
| Dark veil | `rgba(2,6,16,0.52)` | Full-screen overlay above CyberGrid, below content |
| Secondary (30%) | `rgba(2,6,16,0.72)` + `backdropFilter:blur(20px)` | Chat panel, step content cards |
| Accent (10%) | `#da7a4e` (terracotta-2) | Continue button, Sophia name label, step indicator active dot |
| Step indicator inactive | `rgba(218,122,78,0.25)` | Inactive step dots |
| Sophia bubble bg | `rgba(218,122,78,0.08)` | Sophia's chat bubbles |
| User bubble bg | `rgba(255,255,255,0.06)` | User's chat bubbles |
| Input field bg | `rgba(255,255,255,0.05)` | Chat text input |
| Input border | `rgba(255,255,255,0.12)` | Chat text input border |
| Card border | `rgba(0,212,255,0.15)` | Step card outer border (consistent with auth card) |
| Destructive | `#f87171` | Error messages only |
| Text primary | `#f5f0ea` | Main readable text on dark surface |
| Text muted | `rgba(245,240,234,0.45)` | Secondary labels, hints |
| Text accent | `#da7a4e` | Sophia attribution label, active step dot label |

Accent reserved for: Continue button, Sophia name chip, active step indicator dot, loading indicator pulse, user-reply "Send Reply" button.

No raw hex values in component code. Map to the values above via inline style literals — the auth page pattern does not use CSS custom properties on the dark surface; it uses hex/rgba literals directly. Follow this pattern.

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, dot indicator spacing |
| sm | 8px | Sophia name chip padding, bubble inner gap |
| md | 16px | Default element spacing, card inner padding (horizontal) |
| lg | 24px | Section padding, bubble vertical margin, card padding (vertical) |
| xl | 32px | Between wizard step transitions, logo bottom margin |
| 2xl | 48px | Page vertical padding (top/bottom of full-screen wizard) |

Exceptions:
- Chat input bottom padding on mobile: 16px + safe-area-inset-bottom (env(safe-area-inset-bottom))

## Typography

Approved scale: exactly 4 sizes, exactly 2 weights.

| Role | Font | Size | Weight | Line Height | Usage |
|------|------|------|--------|-------------|-------|
| Logotype | var(--serif) | 42px | 600 | 1 | Noēsis wordmark at top of step 1 |
| Narration heading / district name | var(--serif) | 24px | 600 | 1.2 | Step 1 welcome headline; step 3 district name heading |
| Body / message / input / button | var(--serif) / var(--sans-portal) | 16px | 400 or 600 | 1.6 | Sophia chat bubbles (serif 400); user bubbles, input, CTA, ghost buttons (sans 400 or 600) |
| Small labels / badges / loading | var(--mono-portal) / var(--sans-portal) | 11px | 400 or 600 | 1 | Sophia name chip (mono 600), step indicator dots (mono 600), loading text (sans 400), "Sophia is thinking…", district progress dots, ghost nav buttons |

Size-to-role mapping (exhaustive):
- 42px: logotype wordmark only
- 24px: narration heading (step 1), district name heading (step 3)
- 16px: narration body text (step 1, step 3), Sophia chat bubbles, user chat bubbles, chat input field, Continue/Send Reply buttons, ghost nav buttons
- 11px: Sophia name chip "SOPHIA", step indicator dot numbers, loading text "Sophia is thinking…", error state text, metadata badges "PORTAL"/"GENESIS GRID", district progress dot labels

Weight mapping:
- 400 (regular): all body prose, narration paragraphs, Sophia bubbles, user bubbles, chat input, loading text
- 600 (semibold): logotype, narration heading, district name heading, Sophia name chip, step indicator labels, Continue button, Send Reply button, ghost nav button labels

Typography rules:
- Sophia's voice (narration + chat bubbles) always uses `var(--serif)`. This is the defining visual distinction between AI/world text and UI text.
- User-typed text and all interactive chrome use `var(--sans-portal)`.
- Mono is reserved for static labels, badges, metadata — never for prose.
- Italic not used on Sophia bubbles — reserved for future emphasis.

## Wizard Chrome

### Step indicator

Three dots centered above the step card, always visible:

```
● — ● — ●
1   2   3
```

- Each dot: 8px × 8px circle
- Active dot: background `#da7a4e`, box-shadow `0 0 8px #da7a4e`
- Inactive dot: background `rgba(218,122,78,0.25)`
- Connector line between dots: 24px wide, 1px height, `rgba(218,122,78,0.25)`
- No step labels below dots (space is constrained on mobile)
- Margin below indicator before card: 16px

Step indicator sits above the step content card, within the zIndex: 2 content layer.
No back button. No skip button. Forward progression only.

## Step 2 — Sophia Chat + Goal Capture

### Anatomy

```
[CyberGrid full-screen — no highlighting]
[dark veil]

[step indicator ○ ● ○]

[step content card — taller, flexible height]
  ──────────────────────────────────────
  SOPHIA                                 ← mono 11px, #da7a4e label
  [Sophia avatar dot] [bubble]           ← serif 16px bubble
  
  [Sophia bubble ...]
  [User bubble]
  [Sophia bubble ...]
  ...up to 3 exchanges

  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  ← rule line rgba(255,255,255,0.08)

  [text input: "Reply to Sophia..."]    ← sans-portal 16px
  [                     Send Reply →  ] ← secondary accent button

  [Continue →] appears ONLY after Sophia's closing message
  ──────────────────────────────────────
```

### Sophia avatar

- 20px × 20px circle, color `#da7a4e`, opacity 0.85
- Inside: greek letter Σ in mono 11px, color `#020610` (or a simple minimal mark)
- Alternatively: a solid amber dot with a soft glow shadow (`box-shadow: 0 0 6px rgba(218,122,78,0.6)`)
- Appears left-aligned before each Sophia message
- User messages: no avatar — right-aligned bubble only

This is the only visual representation of Sophia in the wizard. No full portrait, no icon set.

### Chat bubble rules

**Sophia bubble:**
- `background: rgba(218,122,78,0.08)`
- `border: 1px solid rgba(218,122,78,0.18)`
- `borderRadius: 4px 12px 12px 12px` (left-anchored shape)
- `padding: 12px 16px`
- `maxWidth: 85%`
- `fontFamily: var(--serif); fontSize: 16px; lineHeight: 1.6; color: #f5f0ea`
- Aligned left

**User bubble:**
- `background: rgba(255,255,255,0.06)`
- `border: 1px solid rgba(255,255,255,0.10)`
- `borderRadius: 12px 4px 12px 12px` (right-anchored shape)
- `padding: 12px 16px`
- `maxWidth: 80%`
- `fontFamily: var(--sans-portal); fontSize: 16px; lineHeight: 1.6; color: #f5f0ea`
- Aligned right (flex justify-content: flex-end)

Vertical margin between messages: 12px. Between Sophia-then-user or user-then-Sophia: 16px.

### Loading state (Sophia is thinking)

Shown after user sends a message, while `POST /api/v1/portal/chat/onboard` is pending (~2s):

- Replace Sophia's next bubble position with a loading row
- 3-dot pulsing indicator: three 8px circles at 0.4s staggered animation using `portal-pulse` keyframe
- Text: "Sophia is thinking…" — sans-portal 11px, `rgba(245,240,234,0.45)`
- No spinner. No progress bar. Dot pulse only.

### Input field

- `width: 100%`
- `background: rgba(255,255,255,0.05)`
- `border: 1px solid rgba(255,255,255,0.12)`
- `borderRadius: 8px`
- `padding: 12px 16px`
- `fontSize: 16px; fontFamily: var(--sans-portal); color: #f5f0ea`
- `placeholder: "Reply to Sophia…"`
- On focus: `borderColor: rgba(218,122,78,0.50)` (terracotta glow)
- Disabled (opacity 0.5) while loading state is active

Send Reply button:
- Inline below input OR attached as suffix icon (Claude's discretion — prefer separate row for touch target)
- If separate row: `background: rgba(218,122,78,0.15); border: 1px solid rgba(218,122,78,0.30); borderRadius: 8px; padding: 8px 20px; color: #da7a4e; fontSize: 16px; fontWeight: 600; fontFamily: var(--sans-portal)`
- Label: "Send Reply"
- Disabled while loading

### Continue button trigger (step 2)

Continue button is HIDDEN until Sophia's closing message is delivered. Detection: the LLM system prompt instructs Sophia to close the conversation when goals have been discussed. The frontend state machine marks the conversation "complete" when `POST /api/v1/portal/chat/onboard` returns a response with a closing signal, OR after the 3rd exchange — whichever comes first.

When triggered: Continue button fades in below the input row with a 200ms opacity transition.
Continue button copy: "Explore the World →"

### Chat panel scroll

- Chat message list is scrollable: `overflowY: auto; maxHeight: 320px` on desktop
- On mobile: `maxHeight: 240px`
- Auto-scroll to bottom after each new message renders

```

  The neural nexus of the Genesis Grid. ← serif 16px, line-height 1.6
  Sophia, Hermes, and Themis live here...

  [● ○ ○ ○ ○]  ← district progress dots (5 districts)

  [< Prev]              [Next District >] ← navigation row (sans-portal 16px)

  [                   Enter the World →] ← appears only on last district
  ──────────────────────────────────────
```

### District progression (step 3)

5 districts cycle in order: AI_CORE → HUB → DATA → DARKWEB → RESIDENTIAL

For each district:
- CyberGrid receives a `highlightDistrict` prop (string | null) — pulse effect on that district's buildings
- Narration card updates with district name + description (pre-scripted from DISTRICT_INFO in CyberGrid.tsx)
- District progress dots: 5 dots below narration, active dot uses `#da7a4e`, inactive `rgba(218,122,78,0.25)`

Navigation buttons (Prev / Next District):
- Prev hidden on first district
- Next label changes to "Enter the World →" (full-width primary button) on the 5th district
- Prev / Next: ghost buttons — `background: transparent; border: 1px solid rgba(255,255,255,0.12); color: rgba(245,240,234,0.70); borderRadius: 8px; padding: 8px 16px; fontSize: 16px; fontFamily: var(--sans-portal)`

### Dark veil step 3

Step 3 dark veil is slightly lighter: `rgba(2,6,16,0.40)` instead of `rgba(2,6,16,0.52)`. This lets the district glow colors from CyberGrid read through more visibly, reinforcing the tour experience.

## Continue Button — Universal Contract

The Continue button is the sole progression mechanism across all steps. No skip. No back.

| State | Appearance |
|-------|-----------|
| Default | `background: #da7a4e; color: #fff; borderRadius: 8px; padding: 16px 24px; fontSize: 16px; fontWeight: 600; fontFamily: var(--sans-portal); width: 100%` |
| Hover | `opacity: 0.88; cursor: pointer` (transition: 0.15s) |
| Disabled | `opacity: 0.40; cursor: not-allowed` |
| Loading (post-tap) | Replace text with "…" + disable; no spinner |
| Fade-in (step 2) | `opacity: 0 → 1` over 200ms when Sophia closes |

Continue button is full-width within the step card content area.

Copy by step:
- Step 1: "Begin →"
- Step 2: "Explore the World →"
- Step 3 (last district): "Enter the World →"

## States and Interactions

### Step transitions

- No animated slide transition between steps — instant re-render of step content card
- CyberGrid remains continuous (same canvas instance, no unmount) across all steps
- Step indicator dots update synchronously on step change

### Error state (step 2 LLM call fails)

Show error inline above input field:

```
background: rgba(184,50,50,0.10)
border: 1px solid rgba(184,50,50,0.30)
borderRadius: 8px
padding: 8px 12px
fontFamily: var(--mono-portal)
fontSize: 11px
color: #f87171
```

Copy: "Sophia is unavailable right now — please try again."

Retry: input field and Send Reply button remain enabled. No automatic retry. User re-sends.

### Goal storage failure (D-08)

If `PATCH /api/v1/portal/auth/me` fails before step 3 loads:
- Log the error silently (console.warn)
- Do NOT block wizard progression
- No error state shown to user — goal storage is non-blocking

### Returning users

If `human_users.onboarding_goal IS NOT NULL` (user already onboarded), `portal/layout.tsx` redirects away from `/portal/onboard` to `/portal` before the wizard renders. The wizard itself does not need to handle this case.

### Mobile considerations

- Chat message list height: 240px max on viewport < 768px
- Input field + Send Reply button stack vertically on mobile (already full-width)
- Continue button: full-width always
- Step card: 100% width minus 32px horizontal margin on mobile
- Touch targets: all interactive elements ≥ 44px height
