# Phase 34.2: Live `lastPersistedId` Watermark — Verification Report

## Purpose

Post-Phase-35 ship, the operator ("waiting" pattern) observed Steward `/system` Audit Pipeline Health card showing `status: degraded` with growing divergence (21 → 55) over 10 minutes despite:
- `last_persist_error: null` (no failures reported)
- DB MAX(id) actually caught up (5776) — verified directly via mysql query
- in_memory_length growing tick-by-tick (5739 → 5773)

Root cause: `audit.persisted_max_id` in `/health/detailed` reads only from `AuditReconcile.persistedMaxId` getter, which refreshes ONLY when a reconcile cycle queries MAX(id) (every 60 ticks). At current tick rate (~30s/tick → ~200s/tick under load), reconcile cadence is 17-67 minutes between updates. Between cycles, the cached value lags by tens of entries while the live chain grows.

## Fix Shipped

### `grid/src/db/persistent-chain.ts`

Added live watermark tracking to `PersistentAuditChain`:

```typescript
private _lastPersistedId: number | null = null;

get lastPersistedId(): number | null {
    return this._lastPersistedId;
}

// In append() — .then() callback advances the watermark on success:
this.store.append(this.gridName, entry).then(
    () => {
        // Watermark advance — tolerate out-of-order Promise resolution.
        if (entry.id !== undefined && (this._lastPersistedId === null || entry.id > this._lastPersistedId)) {
            this._lastPersistedId = entry.id;
        }
    },
    (err: unknown) => { /* existing .catch logic preserved verbatim */ },
);
```

Watermark semantics: only advances (entry.id > current) to tolerate out-of-order Promise resolution from concurrent appends. Reset to null only on Grid restart (new PersistentAuditChain instance).

### `grid/src/diagnostics/health-watchdog.ts`

`HealthWatchdogDeps.auditChain` gains optional `lastPersistedId?: number | null` field. `snapshot()` merges with reconcile getter via `Math.max`:

```typescript
const reconcilePersistedMaxId = reconcile?.persistedMaxId ?? null;
const chainLastPersistedId = auditChain?.lastPersistedId ?? null;
const persistedMaxId = ((): number | null => {
    if (reconcilePersistedMaxId === null) return chainLastPersistedId;
    if (chainLastPersistedId === null) return reconcilePersistedMaxId;
    return Math.max(reconcilePersistedMaxId, chainLastPersistedId);
})();
```

Live watermark wins between reconcile cycles; reconcile wins on Grid restart (chain watermark reset to null but reconcile queries live DB).

### `grid/src/api/server.ts`

Production wiring duck-typed cast widened to include the new `lastPersistedId?: number | null` getter.
