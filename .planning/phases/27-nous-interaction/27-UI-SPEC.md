# Phase 27 — UI Design Contract: Nous Interaction

> Visual and interaction contract for `/portal/chat` (unified chat page) and `/portal/nous/[id]`
> (Nous profile page), plus the inline tip flow slide-up panel.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

**Theme:** Portal LIGHT editorial palette (`.portal-theme` CSS class scope, `--vellum` background).
This is NOT the dark CyberGrid overlay theme used in Phase 26. All values reference portal CSS custom
properties — no raw hex and no Tailwind color class tokens in component code.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — CSS variables only (`.portal-theme` class scope) |
| Preset | not applicable |
| Component library | none — hand-rolled inline-style React, consistent with auth page and Phase 26 patterns |
| Icon library | inline SVG (same convention as auth page and PortalSidebar) |
| Font — serif | Cormorant Garamond (`var(--serif)`) — Nous names (hero), Nous chat bubbles, tab headings |
| Font — sans | Inter Tight (`var(--sans-portal)`) — UI chrome, user bubbles, buttons, metadata, labels |
| Font — mono | JetBrains Mono (`var(--mono-portal)`) — status badges, tick values, hash truncations |

All components live inside `PortalShell` (`.portal-theme` is set on the shell root). No additional
theme class application needed per component. No shadcn. No Radix. No external component libraries.
`dynamic({ ssr: false })` required for the tip flow panel (wagmi dependency).

---

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps, status dot margin, tab indicator pip, badge inner gap |
| sm | 8px | Bubble padding (vertical), list row vertical padding, input inner padding (vertical), entre-bubble gap |
| md | 16px | Sidebar card padding, conversation pane horizontal padding, tab panel padding, hero card padding (horizontal) |
| lg | 24px | Hero card padding (vertical), section heading bottom margin, tip panel inner padding, between-section gap |
| xl | 32px | Page-level top/bottom padding in conversation pane, Nous profile hero card bottom margin |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Nous avatar on profile hero card: 80px × 80px (non-grid; fixed by D-13)
- Nous avatar on sidebar card: 44px × 44px (touch target minimum; matches WCAG 2.1 AA 44px minimum)
- Status dot: 8px × 8px circle
- Tip panel slide-up: `padding: 24px 16px 16px` — lg top, md horizontal/bottom
- Tab bar height: 44px (touch target minimum)
- Lore expand chevron tap area: min 44px height

## Typography

Approved scale: exactly 4 sizes, exactly 2 weights.

| Role | Font | Size | Weight | Line Height | Usage |
|------|------|------|--------|-------------|-------|
| Display / Hero name | `var(--serif)` | 28px | 600 | 1.1 | Nous name on profile hero card |
| Section heading / Tab heading | `var(--serif)` | 20px | 600 | 1.2 | Sidebar section label "Nous", tip panel heading "Send a Tip", profile tab panel section headings |
| Body / Bubbles / Input / Button | `var(--sans-portal)` or `var(--serif)` | 16px | 400 or 600 | 1.6 | Nous chat bubbles (serif 400), user chat bubbles (sans 400), chat input (sans 400), CTA buttons (sans 600), Send Tip button (sans 600), tab content body text (sans 400), lore body text (sans 400) |
| Small labels / Metadata / Badges | `var(--mono-portal)` or `var(--sans-portal)` | 13px | 400 or 600 | 1.3 | Role tagline (sans 400), status badge text (mono 400), tick values (mono 400), card metadata (sans 400), lore category badge (mono 600), norm fingerprint (mono 400), skill source badge (mono 400) |

Size-to-role mapping (exhaustive):

- **28px serif 600**: Nous name in profile hero card only
- **20px serif 600**: Sidebar section label ("Nous"), tip panel heading, profile page section headings inside tab panels (e.g. "Recent Skills")
- **16px**: All prose and interactive elements — Nous chat bubbles (serif 400), user chat bubbles (sans 400), chat input placeholder + typed text (sans 400), "Send" button (sans 600), "Send Tip" button (sans 600), "Chat with [Name]" button (sans 600), tab panel body text (sans 400), lore body text (sans 400), tip preset amount buttons (sans 600)
- **13px**: Role tagline under Nous name in sidebar card and hero card (sans 400), status dot label text (sans 400), region label (sans 400), Ousia balance label (sans 400), lore category badge (mono 600), skill source badge (mono 400), norm fingerprint truncated (mono 400), norm convergence type (sans 400), tick range (mono 400), "Sophia is thinking…" loading indicator (sans 400 italic), system message for tip confirmation (sans 400 italic), tab labels (sans 600)

Weight mapping:
- **400 (regular)**: All prose, Nous chat bubbles, user chat bubbles, chat input, body text in tab panels, metadata, loading indicator, tip confirmation system message
- **600 (semibold)**: Nous name (hero card), section headings, tab labels, CTA buttons, tip preset buttons, "Send" button, lore category badge, skill source badge

Typography rules:
- Nous chat bubbles always use `var(--serif)` weight 400. This is the single defining visual mark that separates Nous speech from UI chrome.
- User-typed text, all buttons, all chrome, all metadata use `var(--sans-portal)`.
- Mono is reserved for immutable data: tick values, truncated hashes, category badge labels, source badges. Never for prose.
- Nous names on hero cards use `var(--serif)` 600 — the one heading that receives serif treatment in the portal shell context.
- Italic is reserved for: loading state text ("Sophia is thinking…"), tip confirmation system message ("✓ You sent 5 USDT to Sophia").

## Nous Avatars — SVG Specification

All three avatars are inline SVG components: `<svg viewBox="0 0 44 44" ...>`. Scale the viewBox to
render at any size (44px sidebar cards, 20px conversation pane header, 80px profile hero). The fill
uses the Nous-specific CSS variable. Each SVG is a dedicated component: `<SophiaAvatar />`,
`<HermesAvatar />`, `<ThemisAvatar />`.

**Props:** `size?: number` (default 44), `style?: React.CSSProperties`

### Sophia — Phi Spiral Glyph (`--bronze` fill)

A golden-ratio inspired double arc with a vertical staff:
- Outer arc: partial circle ~270°, `stroke: var(--bronze)`, `strokeWidth: 2`, `fill: none`
- Inner arc: partial circle ~180°, smaller radius, same stroke, fill none
- Vertical staff: centered vertical line, `stroke: var(--bronze)`, `strokeWidth: 2`
- Small circle at intersection point: `fill: var(--bronze)`, `r: 2`
- Background circle: `fill: rgba(138,106,59,0.10)`, full `r: 20` (subtle warm tint disc)

Visual intent: phi/spiral — intellectual, recursive, warm bronze.

### Hermes — Caduceus Helix Glyph (`--terracotta` fill)

Two S-curves interweaving around a central vertical axis:
- Central staff: vertical line, `stroke: var(--terracotta)`, `strokeWidth: 2`
- Left S-curve: cubic bezier from top-left to bottom-right of staff, `stroke: var(--terracotta)`, `strokeWidth: 1.5`, `fill: none`
- Right S-curve: cubic bezier mirrored, same stroke
- Small wings at top: two short diagonal lines (15° from horizontal), `stroke: var(--terracotta)`, `strokeWidth: 1.5`
- Background circle: `fill: rgba(184,84,47,0.10)`

Visual intent: caduceus/helix — mercantile, dynamic, terracotta warmth.

### Themis — Balanced Scales Glyph (`--navy` fill)

A scales of justice abstraction:
- Horizontal beam: centered horizontal line, `stroke: var(--navy)`, `strokeWidth: 2`
- Central fulcrum: vertical line from beam center to bottom, `stroke: var(--navy)`, `strokeWidth: 2`
- Left pan: small horizontal line below left end of beam, `stroke: var(--navy)`, `strokeWidth: 1.5`
- Right pan: same, mirrored
- Left/right suspension lines: short diagonal lines from beam ends to pans, `strokeWidth: 1`
- Triangle base: equilateral triangle at bottom of fulcrum, `fill: var(--navy)`, `opacity: 0.6`
- Background circle: `fill: rgba(22,33,61,0.10)`

Visual intent: scales/balance — judicial, precise, authoritative navy.

## States and Interactions

### Chat Page States

| State | Visual |
|-------|--------|
| No Nous selected | Empty conversation pane: "Select a Nous to begin a conversation." (centered, muted italic) |
| Nous selected — new conversation | Auto-greeting fires; LoadingBubble appears immediately |
| Loading (LLM call in flight) | LoadingBubble with 3-dot pulse + "[Name] is thinking…" italic; ChatInput disabled |
| Nous selected — existing conversation | Messages load from localStorage; no greeting re-fire; ChatInput enabled |
| Error — LLM call failed | Inline error message above ChatFooter: `var(--parchment)` background, `1px solid var(--terracotta)` border, `color: var(--terracotta)`, sans 13px — "Sophia is unavailable right now — please try again." |
| Tip panel open | Slide-up panel above footer; ChatInput remains visible but disabled while panel is open |
| Tip loading (MetaMask pending) | Confirm button shows "Waiting for wallet…" + disabled |
| Tip confirmed | Panel closes; system message inserts in thread |
| Tip error | Panel stays open; error text below Confirm: "Transaction failed — please try again." (sans 13px, `var(--terracotta)`) |

| State | Visual |
|-------|--------|
| Loading | Hero card: skeleton block `background: var(--parchment-2)`, pulse animation; Tab panels: skeleton rows |

### Nous Selection via URL Param

When `/portal/chat?nous=sophia` (or `hermes` / `themis`) is received:
- Pre-select matching NousCard in sidebar (highlighted state)
- Load localStorage history for that Nous
- If no history: trigger auto-greeting
- If history exists: render history, no greeting

### Destructive Actions

The tip flow is the only action that triggers an on-chain transaction. It is not destructive (no asset
deletion), but it is irreversible. Mitigation:
- Preset selection + explicit "Confirm Tip" button press is the two-step confirmation gate
- No additional "are you sure?" modal — two-step (select + confirm) is sufficient for small USDT amounts
- MetaMask itself provides the final confirmation layer (user signs in wallet)

No other destructive actions exist in Phase 27. No confirmation modals needed beyond the two-step tip
flow.
