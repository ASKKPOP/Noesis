BFS layout algorithm (from PATTERNS.md Pattern 4):
- Find roots: Nous nodes with no incoming edges (i.e., no target === nousId)
- BFS from roots: assign depth (rank) to each node
- Group nodes by depth: x = (positionInGroup + 1) / (groupSize + 1) * VIEWPORT.width
- y = depth * LEVEL_HEIGHT where LEVEL_HEIGHT = VIEWPORT.height / (maxDepth + 1)
- VIEWPORT = { width: 1000, height: 1000 }

**Route handler logic — step by step:**

1. Fetch all audit entries and filter:
```typescript
const entries = audit.all()
    .filter(e => e.eventType === 'skill.taught' || e.eventType === 'skill.inferred');
```

2. Build node and edge sets from the entries:
- For `skill.taught` event:
  - Create Nous node: `{ id: payload.teacher_did, label: lastDIDSegment(payload.teacher_did), type: 'nous' }`
  - Create skill node: `{ id: payload.skill_hash, label: payload.skill_hash.slice(0, 6), type: 'skill' }`
  - Create edge: `{ source: payload.teacher_did, target: payload.skill_hash, tick: payload.tick, type: 'taught' }`
- For `skill.inferred` event:
  - Create skill node: `{ id: payload.skill_hash, label: payload.skill_hash.slice(0, 6), type: 'skill' }`
  - Create Nous node: `{ id: payload.learner_did, label: lastDIDSegment(payload.learner_did), type: 'nous' }`
  - Create edge: `{ source: payload.skill_hash, target: payload.learner_did, tick: payload.tick, type: 'inferred' }`
- Use a `Map<string, node>` keyed by id to deduplicate nodes.

3. `lastDIDSegment` helper: `(did: string) => did.split(':').pop() ?? did`

4. Compute BFS hierarchical layout:
```typescript
const VIEWPORT = { width: 1000, height: 1000 };
// Build adjacency list from edges (direction: source → target)
// Find roots: all node ids that never appear as an edge target
// BFS from all roots simultaneously: assign depth to each node
// Group nodes by depth. For each group:
//   x = (indexInGroup + 1) / (groupSize + 1) * VIEWPORT.width
//   y = depth === 0 ? 50 : depth * (VIEWPORT.height / (maxDepth + 1))
// Nodes unreachable by BFS (isolated nodes) get depth = 0
```

Empty state: if `entries.length === 0`, return `reply.code(200).send({ nodes: [], edges: [] })` immediately (skip layout computation).

5. Error handling: wrap in try/catch, log and return `500` with `{ error: 'lineage query failed' }` on unexpected errors.

**`lastDIDSegment` detail:** DID format is `did:noesis:name`. `did.split(':').pop()` gives the last segment. For skill hashes, the same function is used but for the label we always call `.slice(0, 6)` on the raw hash string.

**Payload access:** The `audit.all()` method returns `AuditEntry[]`. The `payload` field is typed as `Record<string, unknown>`. Cast it:
```typescript
const p = entry.payload as { teacher_did: string; skill_hash: string; learner_did: string; tick: number; parent_hash?: string | null };
```
Do this cast per entry type — separate casts for skill.taught and skill.inferred.
