## Spacing Scale

Inherits the established dashboard rhythm. No new tokens introduced.

| Token | px Value | Tailwind | Usage in Phase 21 |
|-------|----------|----------|-------------------|
| xs | 4px | `p-1` / `gap-1` | Inline icon/dot gaps; SVG label offsets |
| sm | 8px | `p-2` / `gap-2` | Panel row spacing; section inner padding |
| md | 16px | `p-4` | Culture page content padding; panel outer padding |
| lg | 24px | `p-6` | Culture page card padding; section break |
| xl | 32px | `mt-8` / `gap-8` | Top-level section break between the three SVG panels |
| 2xl | 48px | `py-12` | Page top/bottom breathing room |

**Exceptions:**
- `firehose-row: 28px` — pre-existing token (`tailwind.config.ts`); Phase 21 does not introduce new firehose rows.
- SVG canvas: fixed `viewBox="0 0 1000 1000"` (CSS-scaled). Node positions and edge coordinates use raw SVG units. NOT Tailwind spacing tokens. Per D-9-08 + D-21-03 — server-computed `{x, y}` MUST NOT tie to theme spacing.
- SVG `NODE_RADIUS = 6` (raw SVG unit).
- SVG `EDGE_STROKE_WIDTH = 1.5` (raw SVG unit).
- Norm timeline row height: SVG `30` units per norm row (raw SVG unit; total height = norm_count × 30 + padding).

## Typography

Inherits the four-size scale established in Phase 9. No new sizes introduced.

| Role | Size | Tailwind | Weight | Line-Height | Usage in Phase 21 |
|------|------|----------|--------|-------------|-------------------|
| Section heading | 14px | `text-sm` | 600 | 1.25 | "Culture" page h1; "Skill Lineage", "Norm Adoption Timeline", "Lore Contributions" section h2s |
| Body / label | 12px | `text-xs` | 400 | 1.5 | Empty-state copy; loading state copy; panel subtitles; edge type legend labels |
| Meta / caption | 11px | `text-[11px]` | 400 | 1.4 | SVG inline text labels (node labels, tick labels, convergence-type labels); legend entries |
| Monospace DID / hash | 12px | `font-mono text-xs` | 400 | 1.3 | Nous DID nodes (last segment), skill hash labels (6-char), lore hash labels (6-char), fingerprint labels |

**Weight discipline:** Only 400 (regular) and 600 (semibold). No 500 (medium), no 700 (bold). Matches Phase 6–21 precedent.

**Monospace usage:** DID segments, skill hashes, lore hashes, norm fingerprints render in JetBrains Mono via `font-mono`. Section headings and labels render in Inter. Consistent with Phase 9 identity-vs-semantic distinction.

**SVG text sizing:** SVG `<text>` elements use `fontSize="10"` (SVG unit, not px) matching `text-[10px]` at 1:1 scale. This is the D-9-08 inline label pattern used in `relationship-graph.tsx` and verified as readable at 800px canvas width.

### Copywriting style guide (inherited from Phase 9)

- No exclamation marks. No emoji. No "Oops" or "Uh oh."
- Active voice: "Nous begin teaching…" not "Teaching has not yet occurred…"
- Named nouns: "Nous" (capital N), "Grid" (capital G), "tick" (lowercase), "Culture" (capital C as proper noun for the feature surface).
- Tick numbers render as `tick {N}` — never wall-clock time. This is a Grid running on ticks, not a web app.
- 6-char truncated hashes in inline SVG labels (e.g., `a1b2c3`). Full value in `<title>` hover.
- Convergence types are lowercase in SVG labels (`emergent`, `coincidental`), consistent with event payload values.

### Surface 3: NormTimeline

**File (NEW):** `dashboard/src/components/culture/norm-timeline.tsx`

**Data source:** `useNorms()` hook → `GET /api/v1/grid/norms` (existing Phase 19 endpoint)

**X-axis:** Relative ticks (ticks since `norm.candidate`). Per CONTEXT.md Claude's Discretion recommendation. `evidence_tick_range[0]` is tick 0; `evidence_tick_range[1]` is the crystallized tick. Duration = `evidence_tick_range[1] - evidence_tick_range[0]`.

**SVG constants:**
- `VIEWPORT = { width: 1000, height: Math.max(norms.length * 40 + 60, 200) }` (dynamic height)
- `ROW_HEIGHT = 40` (SVG units per norm row)
- `BAR_HEIGHT = 20` (SVG units per norm bar)
- `LABEL_X = 10` (left margin for norm label)
- `TIMELINE_START_X = 200` (x where timeline begins — space for fingerprint label)
- `TIMELINE_END_X = 950` (x where timeline ends)
- `NORM_EMERGENT_FILL = '#7DD3FC'` (brand accent — genuine cultural transmission)
- `NORM_COINCIDENTAL_FILL = '#9CA3AF'` (neutral — no social link detected)

**Per-norm row anatomy:**

```
Y offset = i * ROW_HEIGHT + 30

  <text x={LABEL_X} y={Y + BAR_HEIGHT/2} fontSize="10" fill="#A3A3A3" fontFamily="mono">
    {norm.fingerprint}           {/* 6-char hex fingerprint */}
  </text>
  <text x={LABEL_X} y={Y + BAR_HEIGHT/2 + 12} fontSize="9" fill="#6B7280">
    {norm.participant_count} Nous · {norm.convergence_type}
  </text>
  <rect
    x={TIMELINE_START_X}        {/* all bars start at same x; relative timeline */}
    y={Y}
    width={(TIMELINE_END_X - TIMELINE_START_X) * (duration / maxDuration)}
    height={BAR_HEIGHT}
    fill={convergence_type === 'emergent' ? '#7DD3FC' : '#9CA3AF'}
    rx={3}
  >
    <title>{fingerprint} — {convergence_type} — {participant_count} Nous — {duration} ticks</title>
```

## Interaction Contract

### Culture page state machine

```
Page loads at /grid/culture
  ↓
Three independent SWR fetches fire in parallel:
  useSkillLineage() → GET /api/v1/grid/culture/skills/lineage
  useNorms()        → GET /api/v1/grid/norms
  useLoreGraph()    → GET /api/v1/grid/lore + GET /api/v1/audit/trail?type=lore.cited
  ↓
Each section independently cycles through:
  isLoading → <div role="status">Loading {name}…</div>
  error     → <div role="alert">{Name} could not be loaded.</div>
  data.nodes.length === 0 → <EmptyState title="…" description="…" />
  data.nodes.length > 0   → <svg …> (rendered)
```

### Interaction: read-only

No click handlers on SVG nodes or edges. No elevation dialogs. No modals. No destructive actions. The only interactive controls in Phase 21 are:
1. The Culture tab in TabBar (navigates to `/grid/culture`)
2. The EventTypeFilter `culture` chip (toggles the filter)
3. Native browser hover on SVG `<title>` elements (no JS)

### Keyboard navigation

| Key | Context | Action |
|-----|---------|--------|
| Tab | TabBar | Cycle through all tabs including Culture |
| Enter / Space | Culture tab button | Navigate to `/grid/culture` |
| ArrowLeft / ArrowRight | TabBar focused | Cycle tabs (existing TabBar keyboard behavior — extend to include Culture) |
| Tab | Culture page | Cycle through SVG elements (SVG roots have `role="img"` — they are not individually focusable at the node level; page is read-only) |

**No per-node keyboard navigation:** Phase 21 SVG panels are `role="img"` with a single `aria-label`. Nodes are NOT individually `tabIndex={0}` (unlike Phase 9 RelationshipGraph). Rationale: three panels on one page with potentially many nodes would produce excessive Tab stops. Culture page is read-only observation; per-node focus is deferred to post-v2.4 click-to-inspect.
