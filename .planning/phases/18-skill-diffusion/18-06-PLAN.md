<objective>
Close the two verification gaps that block SKILL-02 and SKILL-03: the `source: observed`
provenance tag is not stored through the quarantine boundary, and `skill.inferred` never
fires for OL-path promotions (sweep always emits SKILL_TAUGHT regardless of origin).

Purpose: The single missing parameter `source='observed'` in observational.py's enqueue()
call cascades into two failures — lost provenance and wrong audit event type at promotion.
Fixing the data plumbing at the quarantine boundary (enqueue → payload_json → sweep →
QuarantineResult → handler dispatch) resolves both gaps in one coherent change set.

Output:
- quarantine.py: enqueue() accepts source kwarg, stores in payload; QuarantineResult gains
  source field; sweep() reads payload['source'] to set it on each result
- observational.py: enqueue() call gains source='observed'
- handler.py: sweep loop emits SKILL_INFERRED for result.source == 'observed',
  SKILL_TAUGHT for all other (peer-taught) promotions
- test_quarantine_store.py: new tests for source tag round-trip and event type selection
- test_observational_filter.py: new test confirming source='observed' is passed to enqueue()
</objective>
