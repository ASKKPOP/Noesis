## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-02-01 | Spoofing | Auth page fetches /me with stale or replayed JWT | accept | Grid jwtVerify rejects expired tokens (24h TTL); same existing auth mechanism |
| T-24-02-02 | Tampering | Region value manipulated before reaching React render | mitigate | Region rendered as JSX text via `{value}` — React escapes HTML entities automatically; no dangerouslySetInnerHTML used |
| T-24-02-03 | Information Disclosure | Wallet balance (ETH/USDT) visible on profile page | accept | User chose to connect wallet; balance is their own data; no server-side secrets involved |
| T-24-02-04 | Denial of Service | /me call fails silently; store has partial user | accept | try/catch around /me call; store retains /verify data; profile shows '—' for unavailable fields; non-fatal |
</threat_model>
