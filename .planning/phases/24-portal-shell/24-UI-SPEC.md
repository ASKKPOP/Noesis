## Design System

| Property | Value |

## Interaction Contract

### Hamburger / Mobile Sidebar (D-08, D-09, D-10)

- **Breakpoint:** Below 768px (`md`) — sidebar hidden, hamburger visible in `PortalHeader` left side
- **Above 768px:** Sidebar always visible; hamburger never rendered
- **Open:** Sidebar slides in from the left as a full-height overlay
- **Close triggers:** Tap backdrop, tap × button inside sidebar header, or navigate to a new route
- **Animation:** CSS `transform: translateX(-100%)` → `translateX(0)` with `transition: transform 0.2s ease`
- **Z-index:** Sidebar overlay at z-index 50; backdrop at z-index 49; all portal content at z-index 0
- **Backdrop:** `rgba(11,18,32,0.40)`, full-viewport, pointer events enabled (tap closes sidebar)
- **Hamburger icon:** Three horizontal lines, SVG 18×18, stroke `var(--ink)`, strokeWidth 2
- **Close button:** Inside sidebar header area (right of logo text), `×` character, 24×24 touch target minimum, color `rgba(200,192,184,0.72)`
- **State owner:** `menuOpen: boolean` state in `PortalShell` only — not Context, not Zustand
- **Props threading:** `PortalHeader` receives `onMenuOpen: () => void`; `PortalSidebar` receives `isOpen: boolean` + `onClose: () => void`

### Live Stats Polling (D-11)

- **Endpoints:** `GET /api/v1/grid/nous` (Active Nous count + names) + `GET /api/v1/grid/state` or `/api/v1/dash/health` (current tick)
- **Polling interval:** 15s (chosen over 10s to reduce flicker on slow connections; acceptable staleness for a dashboard stat)
- **Fetch method:** `fetch` with `credentials: 'include'` on `useEffect` with `setInterval`; clear interval on unmount
- **Fallback behavior:** Show last successful value; if first load fails, show "—" for the stat value and "Grid offline" for sub-label
- **No loading spinner:** Stats cards retain their layout; stale value stays visible until new data arrives

### Profile Balance Row (D-05)

- **Hooks:** Reuse `useBalance` (ETH) and `useReadContract` (USDT) directly from wagmi — same calls as `WalletPanel.tsx`
- **Display:** Single row, one line: `{N.NN} ETH · {N} USDT` + right-aligned `→ Wallet` link
- **Loading state:** Show "—" for balances while hooks are pending; never show spinner in the row
- **"→ Wallet" link:** `Link href="/portal/wallet"`, color `var(--terracotta)`, font `var(--sans-portal)` 12px weight 500

### Region Display (D-01, D-03, D-05)

- **Source:** `useHumanAuthStore().currentUser.region` (once store is extended per D-07)
- **Display:** Title-case (e.g. `'Agora'`); plain text, no badge, no icon
- **Edit hint:** Optional small link "→ Set during onboarding" displayed in `var(--muted)` at 10px if region is `null` or `'agora'` default — Claude's discretion call (CONTEXT.md)
- **Not shown in:** Sidebar footer, header breadcrumb — profile page only per D-06
