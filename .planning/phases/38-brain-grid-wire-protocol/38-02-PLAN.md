# Phase 38 Plan 02: Brain HTTPS REST client + Grid action endpoint

## Objective

Ship the active wire: Brain produces an Ed25519 JWT (via Plan 38-01's `TokenManager`), sends `BrainAction[]` payloads to `POST /api/v1/brain/actions` over HTTPS, and Grid dispatches them through the existing `NousRunner.executeActions()` so the audit chain is appended exactly as today. TLS is enforced at Brain config-load. The Unix-socket path is preserved verbatim for dev/test; setting `GRID_URL` is the explicit opt-in to the network path.

This plan finishes WIRE-01's REST half and completes WIRE-02 by extending `tryDid` to recognize Brain-signed JWTs.

## Context

The current tick flow is Grid → Brain (via Unix socket JSON-RPC). Phase 38 introduces the FUTURE inverted flow Brain → Grid (HTTPS). Per user decision (D-38-A2), both paths coexist in Phase 38 — the env var `GRID_URL` selects which path is active. The local Unix socket is NOT deprecated.

Brain's only existing HTTP call is the lore discovery poll (`brain/src/noesis_brain/rpc/handler.py:649`), which already uses `httpx.AsyncClient`. We reuse that pattern.

Grid's `tryDid` (`grid/src/api/preHandlers/tryDid.ts`) currently verifies JWTs against the Grid's own ES256 key pair (`keyPairPromise`). It already accepts `did:noesis:nous:*` subjects via `ANY_DID_RE` (Phase 37 prep). We extend it: when the JWT header's `alg` is `EdDSA` AND `iss` matches `did:noesis:nous:*`, fetch the public JWK from `brainTokenStore`, verify with `jose.importJWK`, and on success return `{did: payload.sub, tier: 'civic_member', operatorDid: payload.iss}`. Existing ES256 path is preserved.

NousRunner lookup by Civic-DID (D-38-A5) requires a small addition to the `GridCoordinator`. Today, the coordinator stores runners keyed by Nous DID (existence-DID). We add a secondary index `Map<civicDid, NousRunner>` populated when a Civic-DID is bound to a Nous (Phase 37 already issues Civic-DIDs and stores the mapping in `civic_did_registry.existence_did`). The handler in this plan calls a new accessor `coordinator.getRunnerByCivicDid(civicDid: string): NousRunner | undefined`.

**Files this plan touches (none overlap with 38-01):**

- `brain/src/noesis_brain/wire/client.py` (new)
- `brain/src/noesis_brain/__main__.py` (add `validate_grid_url` call in the env factory)
- `brain/src/noesis_brain/rpc/handler.py` (add optional `_grid_wire_client` attribute and branch in `on_tick` / `on_message`)
- `brain/test/wire/test_grid_wire_client.py` (new)
- `grid/src/api/preHandlers/tryDid.ts` (add Brain-JWT verification branch)
- `grid/src/api/routes/brain-wire.ts` (new)
- `grid/src/api/policy.ts` (one new entry)
- `grid/src/api/server.ts` (register the route)
- `grid/src/integration/grid-coordinator.ts` (add `getRunnerByCivicDid`)
- `grid/test/api/brain-wire.test.ts` (new)
- `grid/test/api/tryDid-brain-token.test.ts` (new)

This plan deliberately does NOT touch the files in 38-01 — both plans run in Wave 1 in parallel. The `tryDid` extension uses the `BrainTokenStore` interface only; the concrete instance is wired by Plan 38-01's server changes. To avoid race ordering, both plans add their changes to disjoint regions of `server.ts` (Plan 38-01 adds the `registerBrainTokenRoutes` line; Plan 38-02 adds the `registerBrainWireRoutes` line — the integrator merges both).

**Steps:**

1. Implement `validate_grid_url` and `GridWireClient` in `client.py`:

   ```python
   from __future__ import annotations
   from typing import Any, Optional
   from urllib.parse import urlparse
   import httpx
   from .token_manager import TokenManager

   ALLOWED_SCHEMES = {"https", "wss"}  # wss reserved for 38-04

   def validate_grid_url(url: str) -> None:
       """Raise ValueError if the URL scheme is not https:// or wss://.
       Called at config-load — refuses to start the Brain on plaintext."""
       parsed = urlparse(url)
       if parsed.scheme not in ALLOWED_SCHEMES:
           raise ValueError(
               f"GRID_URL must use https:// or wss:// scheme, got: {url!r} (scheme={parsed.scheme!r})"
           )
       if not parsed.netloc:
           raise ValueError(f"GRID_URL must include a host, got: {url!r}")

   class GridWireClient:
       """Brain → Grid HTTPS REST client. Used when GRID_URL is set."""

       def __init__(
           self,
           *,
           grid_url: str,
           token_manager: TokenManager,
           timeout_seconds: float = 10.0,
       ) -> None:
           validate_grid_url(grid_url)
           self._base_url = grid_url.rstrip("/")
           self._token_manager = token_manager
           self._timeout = timeout_seconds
           self._client: Optional[httpx.AsyncClient] = None

       async def _get_client(self) -> httpx.AsyncClient:
           if self._client is None:
               self._client = httpx.AsyncClient(timeout=self._timeout)
           return self._client

       async def aclose(self) -> None:
           if self._client is not None:
               await self._client.aclose()
               self._client = None

       async def post_actions(
           self,
           actions: list[dict[str, Any]],
           tick: int,
       ) -> httpx.Response:
           """POST a batch of BrainAction dicts to /api/v1/brain/actions.
           Returns the raw httpx.Response so the caller can decide retry/queue policy.
           Does NOT raise on non-2xx — Plan 38-03 wraps this with queue-on-error logic."""
           token = self._token_manager.get_valid_token()
           client = await self._get_client()
           return await client.post(
               f"{self._base_url}/api/v1/brain/actions",
               json={"tick": tick, "actions": actions},
               headers={
                   "Authorization": f"Bearer {token}",
                   "Content-Type": "application/json",
               },
           )
   ```

3. **Grid side — `tryDid.ts`** — extend the bearer-token branch (lines ~43-62):

   ```ts
   // Existing block: jwtVerify against Grid's keyPairPromise.publicKey (ES256).
   // New block (BEFORE the existing one): if the unverified JWT header has alg=EdDSA
   //   AND the unverified payload iss matches did:noesis:nous:*, fetch the brain_tokens
   //   row and verify against THAT public key.

   import { jwtVerify, decodeProtectedHeader, decodeJwt, importJWK } from 'jose';

   const NOUS_DID_RE = /^did:noesis:nous:[a-z0-9_\-]+$/i;

   // Inside tryDid(req, services):
   if (authHeader && authHeader.startsWith('Bearer ')) {
       const token = authHeader.substring('Bearer '.length);
       // First-pass: peek at the header + payload WITHOUT verifying.
       // jose.decodeJwt does not verify — safe for routing decisions only.
       try {
           const hdr = decodeProtectedHeader(token);
           const claims = decodeJwt(token);
           const iss = claims.iss;
           if (hdr.alg === 'EdDSA' && typeof iss === 'string' && NOUS_DID_RE.test(iss)) {
               // Brain-signed JWT path.
               const store = services?.brainTokenStore;
               if (!store) return null;  // not wired in this server build
               if (await store.isRevoked(iss)) return null;
               const rec = await store.getByDid(iss);
               if (!rec) return null;
               // Verify against the stored public JWK.
               const publicKey = await importJWK(rec.publicKeyJwk as JsonWebKey, 'EdDSA');
               const { payload } = await jwtVerify(token, publicKey);
               const sub = payload.sub;
               if (typeof sub === 'string' && ANY_DID_RE.test(sub)) {
                   // D-36-09: Civic-DID revocation check still applies.
                   const didStore = services?.didStore;
                   if (didStore && (await didStore.isRevoked(sub))) return null;
                   return { did: sub, tier: 'civic_member', operatorDid: iss };
               }
               // EdDSA token whose sub doesn't parse → fall through to ES256 path
               // intentionally (defensive — should not happen with our own Brain).
           }
       } catch {
           // Header peek failed or EdDSA verify failed — fall through to ES256.
       }
       // ── EXISTING ES256 block remains unchanged below ──
       try {
           const { payload } = await jwtVerify(token, publicKey /* Grid ES256 */);
           // ... existing code ...
       } catch { /* ... */ }
   }
   ```
