# Phase 38 Plan 03: Offline queue + batch ingest + idempotency

## Objective

Make the wire resilient to network loss. Brain's `GridWireClient` (Plan 38-02) gains a SQLite-backed FIFO buffer (max 10K events) that catches everything it cannot deliver online. On reconnect, Brain replays via a new batch endpoint `POST /api/v1/brain/events/batch`. Each event carries a deterministic idempotency key (`sha256(brain_did:tick:event_type:payload_hash)`, hex-encoded) and Grid uses MySQL `INSERT IGNORE` into a new `brain_event_ingest` table to dedupe — exactly-once at the chain.

Sole-producer discipline holds across the network boundary: accepted events from the batch endpoint flow through the SAME `NousRunner.executeActions` path as `/brain/actions`. The audit chain is never written from outside the in-process sole-producer functions.

## Context

Plan 38-02 left `GridWireClient.post_actions` returning the raw `httpx.Response`. Today it logs non-2xx and continues. This plan replaces that policy with: enqueue on any failure (transport exception OR status ≥ 500), and run a background replay task that drains the queue when the network recovers.

Per research Pitfall 8, the 10K cap is a deliberate lossy buffer — old events fall off first. Document this. The queue lives at `~/.noesis/brain/wire_queue.db` (or `BRAIN_WIRE_QUEUE_PATH` env override) so it survives Brain restarts.

Per user decision D-38-A8: idempotency key formula is `sha256(f"{brain_did}:{tick}:{event_type}:{payload_hash}")` with colon separators, hex output. `payload_hash` is `sha256(json.dumps(payload, sort_keys=True, separators=(',', ':'))).hexdigest()` — canonical JSON (sorted keys, no whitespace). The formula is documented in `wire/queue.py` with a `# CANONICAL IDEMPOTENCY KEY FORMULA` block.

`brain_event_ingest` table is the dedup gate. It is NOT the audit chain. Its primary key is the idempotency key (CHAR(64) sha256 hex). A duplicate submit just bumps the duplicate counter and is skipped — the audit chain is untouched. Accepted events are forwarded to `NousRunner.executeActions` (Plan 38-02 exposed `dispatchExternalActions(actions, tick)`).

1. Implement `WireQueue` in `queue.py`:

   ```python
   from __future__ import annotations
   from dataclasses import dataclass
   from pathlib import Path
   from typing import Optional
   import hashlib
   import json
   import sqlite3
   import time

   # ───────────────────────────────────────────────────────────────────────
   # CANONICAL IDEMPOTENCY KEY FORMULA — DO NOT CHANGE WITHOUT MIGRATION.
   #
   # key = sha256(f"{brain_did}:{tick}:{event_type}:{payload_hash}").hexdigest()
   # payload_hash = sha256(canonical_json(payload)).hexdigest()
   # canonical_json = json.dumps(payload, sort_keys=True, separators=(",", ":"))
   #
   # Per Phase 38 D-38-A8 + WIRE-04. Colon separators prevent prefix collision.
   # Grid stores this key as CHAR(64) PRIMARY KEY in brain_event_ingest.
   # ───────────────────────────────────────────────────────────────────────

   QUEUE_CAPACITY = 10_000

   @dataclass
   class QueuedEvent:
       row_id: int
       idempotency_key: str
       brain_did: str
       tick: int
       event_type: str
       payload: dict
       enqueued_at: int

   def _canonical_json(payload: dict) -> str:
       return json.dumps(payload, sort_keys=True, separators=(",", ":"))

   def derive_idempotency_key(
       *, brain_did: str, tick: int, event_type: str, payload: dict
   ) -> str:
       payload_hash = hashlib.sha256(
           _canonical_json(payload).encode("utf-8")
       ).hexdigest()
       material = f"{brain_did}:{tick}:{event_type}:{payload_hash}"
       return hashlib.sha256(material.encode("utf-8")).hexdigest()

   class WireQueue:
       def __init__(self, db_path: str | Path) -> None:
           self._db_path = str(db_path)
           self._conn = sqlite3.connect(self._db_path, isolation_level=None)
           self._conn.execute("PRAGMA journal_mode=WAL")
           self._conn.execute("PRAGMA synchronous=NORMAL")
           self._conn.execute("""
               CREATE TABLE IF NOT EXISTS wire_queue (
                   id              INTEGER PRIMARY KEY AUTOINCREMENT,
                   idempotency_key TEXT    NOT NULL UNIQUE,
                   brain_did       TEXT    NOT NULL,
                   tick            INTEGER NOT NULL,
                   event_type      TEXT    NOT NULL,
                   payload_json    TEXT    NOT NULL,
                   enqueued_at     INTEGER NOT NULL
               )
           """)
           self._conn.execute(
               "CREATE INDEX IF NOT EXISTS idx_enqueued_at ON wire_queue (enqueued_at)"
           )

       def size(self) -> int:
           cur = self._conn.execute("SELECT COUNT(*) FROM wire_queue")
           return int(cur.fetchone()[0])

       def enqueue(
           self,
           *,
           brain_did: str,
           tick: int,
           event_type: str,
           payload: dict,
           clock: Optional[callable] = None,
       ) -> str:
           """Insert one event. On capacity overflow, delete oldest row(s) in same tx.
           Returns the idempotency_key (caller may log it). Duplicate keys are a
           no-op (UNIQUE constraint catches re-enqueue of the same logical event)."""
           key = derive_idempotency_key(
               brain_did=brain_did, tick=tick, event_type=event_type, payload=payload
           )
           now = int((clock or time.time)())
           try:
               with self._conn:
                   # Drop oldest until below cap.
                   while True:
                       count = self._conn.execute(
                           "SELECT COUNT(*) FROM wire_queue"
                       ).fetchone()[0]
                       if count < QUEUE_CAPACITY:
                           break
                       self._conn.execute(
                           "DELETE FROM wire_queue WHERE id = (SELECT MIN(id) FROM wire_queue)"
                       )
                   self._conn.execute(
                       """INSERT OR IGNORE INTO wire_queue
                          (idempotency_key, brain_did, tick, event_type, payload_json, enqueued_at)
                          VALUES (?, ?, ?, ?, ?, ?)""",
                       (key, brain_did, tick, event_type, _canonical_json(payload), now),
                   )
           except sqlite3.Error as exc:
               # Surface — caller logs. We do NOT want silent loss.
               raise
           return key

       def dequeue_batch(self, batch_size: int = 100) -> list[QueuedEvent]:
           cur = self._conn.execute(
               """SELECT id, idempotency_key, brain_did, tick, event_type, payload_json, enqueued_at
                  FROM wire_queue ORDER BY id ASC LIMIT ?""",
               (batch_size,),
           )
           out: list[QueuedEvent] = []
           for row in cur.fetchall():
               out.append(QueuedEvent(
                   row_id=row[0],
                   idempotency_key=row[1],
                   brain_did=row[2],
                   tick=row[3],
                   event_type=row[4],
                   payload=json.loads(row[5]),
                   enqueued_at=row[6],
               ))
           return out

       def mark_acked(self, row_ids: list[int]) -> None:
           if not row_ids:
               return
           placeholders = ",".join("?" * len(row_ids))
           with self._conn:
               self._conn.execute(
                   f"DELETE FROM wire_queue WHERE id IN ({placeholders})",
                   row_ids,
               )

       def close(self) -> None:
           self._conn.close()
   ```

   ```python
   async def post_actions(
       self, actions: list[dict[str, Any]], tick: int
   ) -> None:
       """Try online delivery; on failure, enqueue each action and trigger replay later."""
       if not actions:
           return
       try:
           resp = await self._do_post_actions(actions, tick)
           if 200 <= resp.status_code < 300:
               # Online success — also attempt to drain anything previously queued.
               await self._maybe_replay()
               return
           if resp.status_code >= 500 or resp.status_code == 503:
               # Server-side transient — queue and continue.
               self._enqueue_all(actions, tick)
               return
           # 4xx is a programmer / auth error — log loudly, do NOT silently queue.
           log.error(
               "[Brain] grid_wire actions rejected: status=%d body=%s",
               resp.status_code, resp.text[:200],
           )
       except (httpx.RequestError, httpx.TimeoutException) as exc:
           log.warning("[Brain] grid_wire actions transport error, queueing: %s", exc)
           self._enqueue_all(actions, tick)

   def _enqueue_all(self, actions: list[dict[str, Any]], tick: int) -> None:
       if self._queue is None:
           log.warning("[Brain] grid_wire actions failed but no queue configured — DROPPED")
           return
       for act in actions:
           event_type = act.get("action_type", "unknown")
           try:
               self._queue.enqueue(
                   brain_did=self._brain_did,
                   tick=tick,
                   event_type=event_type,
                   payload=act,
               )
           except Exception:
               log.exception("[Brain] wire_queue enqueue failed for action_type=%s", event_type)
   ```

3. Add a replay routine:

   ```python
   async def _maybe_replay(self) -> None:
       """Drain the queue in batches. Caller MAY ignore — idempotency makes retry safe."""
       if self._queue is None or self._queue.size() == 0:
           return
       if self._replay_lock.locked():
           return  # another replay is in progress
       async with self._replay_lock:
           while True:
               batch = self._queue.dequeue_batch(self._replay_batch_size)
               if not batch:
                   break
               body = {
                   "events": [
                       {
                           "idempotency_key": evt.idempotency_key,
                           "brain_did": evt.brain_did,
                           "tick": evt.tick,
                           "event_type": evt.event_type,
                           "payload": evt.payload,
                       }
                       for evt in batch
                   ]
               }
               token = self._token_manager.get_valid_token()
               client = await self._get_client()
               try:
                   resp = await client.post(
                       f"{self._base_url}/api/v1/brain/events/batch",
                       json=body,
                       headers={"Authorization": f"Bearer {token}"},
                   )
               except (httpx.RequestError, httpx.TimeoutException):
                   # Network still bad — stop draining; events stay queued.
                   return
               if 200 <= resp.status_code < 300:
                   # Grid returns {accepted: int, duplicate: int, total: int}.
                   # We delete ALL rows in the batch regardless of accepted vs duplicate
                   # — duplicate means Grid already has it, also safe to delete locally.
                   self._queue.mark_acked([evt.row_id for evt in batch])
               else:
                   log.error(
                       "[Brain] grid_wire batch replay rejected: status=%d body=%s",
                       resp.status_code, resp.text[:200],
                   )
                   # Do NOT mark acked — keep events queued for next attempt.
                   return
   ```

   ```ts
   import type { Pool } from 'mysql2/promise';

   export interface BrainWireEvent {
       idempotencyKey: string;   // 64-char hex
       brainDid: string;
       tick: number;
       eventType: string;
       payload: Record<string, unknown>;
   }

   export interface IngestResult {
       accepted: number;
       duplicate: number;
       total: number;
       acceptedKeys: string[];   // idempotency_keys that landed (NOT duplicates)
   }

   export class BrainEventIngestStore {
       constructor(private opts: { gridName: string; pool: Pool }) {}

       /** INSERT IGNORE per event. Returns counts + the keys that were actually accepted. */
       async ingestBatch(events: BrainWireEvent[]): Promise<IngestResult> {
           let accepted = 0;
           let duplicate = 0;
           const acceptedKeys: string[] = [];
           const now = Date.now();
           for (const evt of events) {
               const [result] = await this.opts.pool.execute(
                   `INSERT IGNORE INTO brain_event_ingest
                       (grid_name, idempotency_key, brain_did, tick, event_type, payload, received_at)
                       VALUES (?, ?, ?, ?, ?, ?, ?)`,
                   [
                       this.opts.gridName,
                       evt.idempotencyKey,
                       evt.brainDid,
                       evt.tick,
                       evt.eventType,
                       JSON.stringify(evt.payload),
                       now,
                   ],
               );
               const affected = (result as { affectedRows: number }).affectedRows;
               if (affected === 1) {
                   accepted++;
                   acceptedKeys.push(evt.idempotencyKey);
               } else {
                   duplicate++;
               }
           }
           return { accepted, duplicate, total: events.length, acceptedKeys };
       }
   }
   ```

1. **Batch route handler** in `brain-wire.ts`:

   ```ts
   // POST /api/v1/brain/events/batch
   // Body: { events: BrainWireEvent[] }  (each event has idempotency_key + payload)
   //
   // Flow:
   //   1. tryDid resolves civic_did from JWT sub.
   //   2. Look up NousRunner by civic_did (same lookup as /actions).
   //   3. Validate every event has idempotency_key (64-hex), brain_did, tick, event_type, payload.
   //   4. Call brainEventIngestStore.ingestBatch — returns accepted/duplicate counts + acceptedKeys.
   //   5. For each ACCEPTED event, build a BrainAction from {event_type, payload} and dispatch
   //      via runner.dispatchExternalActions([action], event.tick).
   //      Duplicates are NOT dispatched — they're already on the chain.
   //   6. Return { accepted, duplicate, total }.
   //
   // R-31-01 preservation: audit.append fires from the same sole-producer functions
   // as the live path. The ingest table is a SEPARATE gate; it does NOT write to audit_trail.
   ```

   Implementation notes:
   - Cap `events.length` at 500. Return 413 on overflow.
   - Validate each event in a single pass; on any malformed entry, return 400 with `{error:'invalid_event', index:N, reason}`. Do NOT partially ingest.
   - The idempotency key validation regex is `/^[a-f0-9]{64}$/`.
   - Bracket the dispatch loop in try/catch per event so one bad action doesn't abort the whole batch; on per-event dispatch failure log Pino `error` and skip dispatch for that event but DO NOT delete its ingest row (the duplicate-on-retry will be a no-op anyway because the dispatch already produced the audit entry on the first successful try… wait — no, if dispatch failed there IS no audit entry. In that case the next retry will find the ingest row already present and will NOT dispatch. This is a known limitation. Document it).

     ```
     CAVEAT: if dispatch raises AFTER the ingest INSERT, subsequent replays will treat
     the event as a duplicate and skip dispatch — producing a silent gap. To mitigate:
     wrap ingest + dispatch in a per-event ordering: dispatch FIRST (idempotent in
     practice for our sole-producer functions), then ingest. If dispatch raises,
     do NOT ingest; the next replay will retry.
     ```

     Apply this ordering: **dispatch then ingest, per event**. Update the handler accordingly. Sole-producer functions are designed to be safe under re-entry (they all use `INSERT IGNORE` on audit_trail via PersistentAuditChain).
