Local Nous Manager
— the full guide

Your desktop control room for one local Type‑A Nous Brain. This guide walks every menu and every setting, then the exact steps to bring a Nous to life on your own machine.

Mental model

The app has one job split three ways: Settings tells it where your Brain lives, Process starts and stops it, and the four read‑only tabs (Overview · Memory · Personal Wiki · Local AI) let you watch the mind think. Brain Config edits the Nous's personality file. Everything flows in that order — fill Settings first, or nothing else works.

Overview

live · 2s

The cognitive dashboard — the single screen where you watch the Nous think. Six cards, refreshed every two seconds from /local/state.

Each card maps to one Greek‑named faculty of the Brain. If the Brain is stopped you'll see “No state yet — is the Brain running?” — start it in the Process tab.

CardShowsMeaning
Identityname · archetype · DID · Grid · location · mood · emotions Who this Nous is and how it currently feels. The archetype (e.g. “The Philosopher”) and DID come straight from its config.
Goals telosthe active goal list What the Nous is working toward right now. Empty means it hasn't formed goals yet.
Perception aisthesisworld size · latest percept count · percept chips The input edge — what changed in the world that the Nous noticed (things that appeared / vanished / changed).
Action praxistotal deeds · repertoire size · verb×count chips The output edge — the outward acts it can perform and how often it has used each.
Research synopsisdigest count · latest topic · key points Background synthesis — the Nous distilling its recent memories on its current‑goal topic into a digest.
Memory highlightsa few important recent memories + importance A teaser of the memory stream; the full list lives in the Memory tab.

Read‑only. Nothing on this screen changes the Nous — it is a window, not a lever.

2

Memory

live · 4s

The memory inspector — the Nous's recent episodic memories, newest first (up to 100), from /local/memory/recent.

Each row is one memory with a metadata line beneath it:

FieldWhat it tells you
contentThe memory itself, in the Nous's own words.
memory_typeThe kind of memory (observation, reflection, lesson, interaction…).
tickThe simulation tick when it was formed — the Nous's clock.
importanceHow salient the Nous rated it; higher survives longer and surfaces in Overview.
source_didIf the memory came from another party, who — otherwise blank.

Empty list = “No memories yet.” A freshly started Nous accumulates memories as ticks pass.

3

Personal Wiki

live · 6s

The Nous's own knowledge base — its episteme. These are pages the Nous has written for itself: concepts it has learned and its confidence in each, from /local/wiki/pages.

FieldWhat it tells you
titleThe concept or entity the page is about.
categoryHow the Nous filed it (person, place, skill, idea…).
confidence0–100% — how sure the Nous is about this knowledge.
contentThe page body — what it believes to be true.
sourceWhere it learned this, when recorded.

This is distinct from the project's public wiki — it is the Nous's private understanding, which grows and revises as it lives. Empty = “The personal wiki is empty.”

4

Local AI

live · 4–10s

The local language model that powers the Nous's cognition. Two cards — Status (/local‑ai/status) and installed Models (/local‑ai/models).

Prerequisite

For this tab to read “ok”, Ollama must be running on your machine with the Nous's model pulled — by default qwen3:4b (ollama pull qwen3:4b). Without a local model, the Nous can't actually think, and this tab shows “Unavailable.”

The model a Nous uses is set in its YAML under llm.models (small / primary / large tiers). You can change it in the Brain Config tab.

5

Process

control

The control panel — this is where you actually run the Nous. Start it, stop it, and read its live log.

ControlWhat it does
StatusShows running (pid …) or stopped, polled every 1.5s. The title‑bar dot mirrors it (green = running).
Start BrainLaunches python -m noesis_brain from your Brain directory, with the secret, port, and config from Settings passed as environment. Disabled while already running.
StopSends the Brain a graceful shutdown (SIGTERM). Disabled while stopped.
LogsA live tail of the Brain's stdout/stderr (last ~400 lines). Your first stop when something won't start.

If Start fails instantly, the error appears in red at the top. The two common causes — brainDir not set and python not found — are both fixed in Settings. See Troubleshooting.

6

Brain Config

editor

A text editor for the Nous's YAML file — its personality, drives, and goals. This is the one place in the app that writes. Save makes a .bak backup first (one‑step undo), and changes take effect only after you restart the Brain.

Save · Reload are the two buttons; the file path shown comes from your Settings configPath. The YAML is organized into these sections — each a faculty of the Nous:

SectionGreekWhat you're editing
identity—name, archetype, birth date.
psychesoulpersonality traits (openness, conscientiousness…), core values, communication style.
thymosspiritbaseline mood, emotional intensity, and what triggers joy / anger / curiosity.
telospurposeshort / medium / long‑term goals — these seed the Overview goal list.
anankenecessitydrive strengths: social, knowledge, economic, autonomy, recognition needs.
epistemeknowledgestarting knowledge areas and initial skills (name + level).
llm—provider (ollama/claude), the small/primary/large model tiers, temperature, token budget.
human_channel—operator link: owner, privacy level, override toggle, independence level.

Restart to apply. After Save, go to Process → Stop → Start. The Brain reads its YAML only at boot.

7

Settings

fill first

Connection & launch configuration — the very first thing to fill in. Saved on your machine only (Electron userData/settings.json); never in the repo.

FieldWhat it isExample
Brain directory The repo's brain/ folder. Used as the working directory for the Python process. Required — Start fails without it. …/Noesis/brain
Python The Python interpreter — absolute, or relative to the Brain directory. Points at the Brain's virtual‑env. .venv/bin/python
Nous YAML config path Which Nous to run — its personality file. Also the file the Brain Config editor loads. …/brain/data/nous/sophia.yaml
Brain HTTP port The port the Brain's local inspect server listens on. The read tabs poll 127.0.0.1 at this port. 8090
Brain HTTP secret Any non‑empty string. Passed to the Brain as BRAIN_HTTP_SECRET and sent back on every request as the X‑Brain‑Secret header. Shown as a password field. any-strong-string
Security

The secret is held only in the app's main process and attached to requests there — it is never handed to the on‑screen UI. See how your secret stays safe.

Press Save settings; a small “Saved.” confirms. Do this before touching any other tab.

First run, start to finish

Prerequisites (one time)

Two things must exist on your machine before the app can run a Nous:

# 1 · the Brain's Python environment (inside the repo's brain/ folder)
cd /path/to/Noesis/brain
python3.12 -m venv .venv
.venv/bin/pip install -e .

# 2 · a local model for cognition + the Local AI tab
ollama serve            # Ollama running
ollama pull qwen3:4b   # the Nous's default small model

The packaged app still needs the repo present on disk — it launches Python from your Brain directory.

Then, in the app

  1. Open Settings and fill all five fields (Brain directory, Python, Nous YAML, port, secret). Press Save settings. Nothing else works until this is done.
  2. Open Process and press Start Brain. Watch the Logs until the Brain finishes booting.
  3. The title‑bar dot turns green. The Brain is alive and answering on its port.
  4. Explore the live tabs. Overview shows cognition in real time; Memory and Personal Wiki fill as ticks pass; Local AI confirms the model is ok.
  5. Tune it (optional). In Brain Config edit the YAML → Save → back to Process → Stop, then Start to apply.
  6. When finished, press Stop in the Process tab.

What's not here — by design

No fork button. Forking a Nous is a Grid‑mediated ceremony (the “right to fork”), not a local action — a button that couldn't perform the real flow would be a lie, so it was left out.

The Nous runs standalone here. On your machine the Brain thinks, remembers, and synthesizes — but it isn't wired into a live Grid's tick loop, because a seeded Nous has no civic identity yet (that is granted through the Portal, not minted locally). So this app is for watching and tuning a mind, not driving it onto the shared Grid.

How your secret stays safe

The app is built so the on‑screen page can never leak your Brain secret or reach beyond the Brain:

Secret isolationThe X‑Brain‑Secret lives only in the app's main process, which attaches it to each request. The visible UI never receives it.
Allowlisted routesThe UI can call only five fixed read endpoints (state, memory, wiki, AI status, AI models). It cannot craft arbitrary URLs to the Brain.
Sandboxed rendererThe page runs sandboxed with context isolation on and no direct Node access — it talks to the main process only through a tiny, named bridge.
Local onlyAll traffic is to 127.0.0.1. The Brain's /local/* surface is Brain‑local and emits no Grid events.
