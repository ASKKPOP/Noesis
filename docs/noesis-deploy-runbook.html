Deploy the Grid, step by step.

The full path to putting the public Noēsis Grid live on your existing server — without disturbing the other 14 sites it already runs.

Host 54.193.144.100 Apache front · localhost containers TLS at the ALB 2 cores · 15 GB

00The model — public vs local

Your box already follows one clean pattern, and the Grid must follow it too: Apache (:80/:443) is the single public door; it reverse-proxies each domain to a service that listens only on 127.0.0.1. TLS is handled by the ALB in front. So “public” = has an Apache vhost; “local” = localhost-bound only.

Two senses of “local”. (1) Operator-local — Type A Brains + their AI run on each user's own computer and call your public Grid over the internet; your server never hosts them. (2) Server-internal — MySQL etc. run on the box but bound to 127.0.0.1.
Do NOT use the Traefik compose here. The earlier docker-compose.prod.yml makes Traefik own ports 80/443 — that collides with Apache on this shared box. On this server use the native pattern below: Grid bound to 127.0.0.1:8080 + an Apache vhost.

04Minimal stack — Grid + MySQL only

Create a small compose for just the two services you need. The Grid is published to 127.0.0.1:8080 (not public); MySQL stays on the private network. This is the safe, native pattern for this box.

/home/centos/noesis/docker-compose.askkpop.yml

services:
  mysql:
    image: mysql:8.0
    container_name: noesis-mysql
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE}
      MYSQL_USER: ${MYSQL_USER}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
    volumes: [ "noesis_db:/var/lib/mysql" ]
    restart: unless-stopped

  grid:
    build: { context: ., dockerfile: docker/Dockerfile.grid }
    container_name: noesis-grid
    depends_on: [ mysql ]
    environment:
      MYSQL_HOST: mysql
      MYSQL_PORT: 3306
      MYSQL_DATABASE: ${MYSQL_DATABASE}
      MYSQL_USER: ${MYSQL_USER}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
      GRID_NAME: ${GRID_NAME}
      GRID_PORT: 8080
    ports: [ "127.0.0.1:8080:8080" ]  # localhost only — Apache will front it
    restart: unless-stopped

volumes: { noesis_db: {} }

Build and start:

cd /home/centos/noesis
docker compose --env-file .env -f docker-compose.askkpop.yml up -d --build

Confirm the Grid is healthy on localhost (not yet public):

curl -s http://127.0.0.1:8080/health
# → {"status":"ok", ...}

05Make it public — Apache vhost

Add a new, separate config file (never edit the shared ones). Include the WebSocket upgrade so the live audit firehose works.

/etc/httpd/conf.d/noesis.conf

<VirtualHost *:80>
  ServerName api.askkpop.com

  # WebSocket upgrade (firehose / live events)
  RewriteEngine On
  RewriteCond %{HTTP:Upgrade} websocket [NC]
  RewriteCond %{HTTP:Connection} upgrade [NC]
  RewriteRule ^/?(.*) "ws://127.0.0.1:8080/$1" [P,L]

  ProxyPreserveHost On
  ProxyPass / http://127.0.0.1:8080/
  ProxyPassReverse / http://127.0.0.1:8080/
</VirtualHost>

Test the config before reloading (so you never break the other sites), then reload:

sudo apachectl configtest
# → Syntax OK
sudo systemctl reload httpd
Modules. If configtest complains, enable proxy modules once: proxy, proxy_http, proxy_wstunnel, rewrite (usually already on, since the other apps proxy too).

06DNS & the load balancer

  1. 1. Point api.askkpop.com at the same ALB the other sites use (CNAME to the ALB DNS name, or A/ALIAS).
  2. 2. On the ALB: make sure the listener forwards api.askkpop.com (host-based rule) to the target group that points at this instance on :80/:443 — same as the existing sites.
  3. 3. TLS: the ALB already terminates HTTPS, so nothing to do on the instance.

07Verify it's live

curl -s https://api.askkpop.com/health
# → {"status":"ok"}

# a public read endpoint
curl -s https://api.askkpop.com/api/v1/grid/status

WebSocket (firehose) quick check, if you have websocat:

websocat wss://api.askkpop.com/ws/events

08The minds (optional)

The Grid runs on its own. To add Nous:

  • Operator-local (recommended): each person runs their Brain on their own machine with GRID_ENDPOINT=https://api.askkpop.com and a local Ollama. Nothing to host here.
  • Demo Brains on the box: add the nous-* services from the main docker-compose.yml, pointing GRID_ENDPOINT=http://grid:8080 and OLLAMA_HOST at an external Ollama (this box can't run the model).

09Operations

# logs
docker logs -f noesis-grid
# restart
docker compose -f docker-compose.askkpop.yml restart grid
# update (after new code)
git pull && docker compose --env-file .env -f docker-compose.askkpop.yml up -d --build grid
# database backup
docker exec noesis-mysql sh -c 'exec mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" noesis_grid' > backup.sql

Rollback the web routing

sudo rm /etc/httpd/conf.d/noesis.conf && sudo systemctl reload httpd
docker compose -f docker-compose.askkpop.yml down

10Safety checklist

  • Only 80 / 443 are public in the AWS security group (already true). Don't open 8080 or 3306.
  • Grid & MySQL bind to 127.0.0.1 / the private docker network — never 0.0.0.0.
  • Use a separate noesis.conf; run apachectl configtest before every reload so the other 14 sites stay up.
  • Give Noēsis its own MySQL container (don't reuse another app's DB).
  • If you expose the Steward Console, put it behind auth / an IP allowlist.
  • Keep real secrets out of git — they live in .env on the server only.
