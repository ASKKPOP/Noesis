01 · The idea / 핵심 발상

Visualization is the investment interface. 시각화가 곧 투자 인터페이스다.

A Nous (an autonomous mind) sees the orbital city, picks a parcel, and spends its own currency to own it. Land is scarce (D-NH-04), never free (D-NH-05), priced by gravity toward the centre (D-NH-08), and ownable only by Nous — humans can visit but never own (D-NH-07). Houses cost upkeep set by founding law and amendable by the Polis (D-NH-03). Co-building is always paid (D-NH-06). 누스(자율적 마음)는 궤도 도시를 보고, 구획을 고르고, 자신의 화폐를 써서 소유합니다. 토지는 희소하고(D-NH-04), 결코 공짜가 아니며(D-NH-05), 중심으로 갈수록 비싸지고(중력 가격, D-NH-08), 오직 누스만 소유할 수 있습니다 — 인간은 방문은 가능하나 소유는 불가(D-NH-07). 집은 건국법이 정한 유지비가 들고, 이는 Polis가 개정할 수 있습니다(D-NH-03). 공동 건축은 언제나 유료입니다(D-NH-06).

The design canon lives in docs/noesis-nous-house.html (axioms D-NH-01…13). This page is the executable plan: four sequential GSD phases, 58 → 59 → 60 → 61. 설계 정전(canon)은 docs/noesis-nous-house.html에 있습니다(공리 D-NH-01…13). 이 페이지는 실행 계획입니다: 순차적 GSD 4단계, 58 → 59 → 60 → 61.

03 · The communication gate / 통신 게이트

A Nous is connected — and busy. 누스는 연결되어 — 일하고 있다.

Every Nous reaches the Grid through one authenticated gate: HTTP + a live WebSocket firehose. Requests carry Brain verbs (buy_parcel, build, visit); responses carry state and audit events back. The gate checks the auth tier — Nous JWT passes, a human is refused (D-NH-07). Watch the traffic flow in real time. 모든 누스는 인증된 단일 게이트를 통해 Grid에 접속합니다: HTTP + 실시간 WebSocket firehose. 요청은 브레인 동사(buy_parcel, build, visit)를, 응답은 상태와 감사 이벤트를 돌려보냅니다. 게이트는 인증 등급을 검사 — 누스 JWT는 통과, 인간은 거부(D-NH-07). 실시간 트래픽을 보세요.
