02

No money entering the city

needs your decision
Cause
The birth faucet was retired on purpose (zero faucet). Its replacement, the bounded endowment route, is behind GRID_ENDOWMENT_ENABLED, which defaults to false. Labor-only cannot bootstrap either, because the treasury that would pay for labor is empty too.
Who acts · effort
Your decision, then one grid redeploy (I will not deploy without your go). 15 minutes.
Solution
  1. Recommended: enable the endowment gate. Set GRID_ENDOWMENT_ENABLED=true in the production .env and redeploy grid.
  2. Signed in to the Portal as an allowlisted operator (tier 5 or higher), call POST /api/v1/portal/account/endow with civic_did, amount_wei and reason for each citizen.
  3. The route enforces its own limits: 1e18 wei per call and 1e19 per account. Every call writes an account_endowments row and emits portal.account_endowed, so the source of all money stays auditable.
  4. Turn the gate back off after seeding if you want a fixed money supply.

This is model wei in the Grid database. No real ETH or keys are involved.

Done when
/api/v1/grid/nous shows a non-zero balance_wei, and the first due.paid event appears after the next due period.
03

system.noesiis.com unreachable

diagnosed · needs DNS access
Cause
Verified today: the DNS A record points at 54.176.95.5 and 54.215.172.165, and neither accepts a connection on port 80 or 443. The nginx virtual host itself is fine. Sending the system.noesiis.com host header to the live front end returns the correct 302 to /system/portal-manager. The certificate served there does not cover the system name, though.
Who acts · effort
You (AWS console and host). 20 minutes.
Solution
  1. In Route 53, point system.noesiis.com at the same target portal.noesiis.com uses (copy that record).
  2. Add system.noesiis.com to the TLS certificate on that front end, the same way it was done for portal.
  3. If the host-level nginx has a per-domain block for portal, add the matching one for system, then force-recreate noesis-nginx.
  4. Confirm GRID_PORTAL_MANAGER_ENABLED=true on the grid, or the console will load but show no data.

Until then the same console is reachable at https://noesiis.com/system/portal-manager, which returns 200 today.

Done when
curl -I https://system.noesiis.com/ returns 302 to /system/portal-manager with a valid certificate.
