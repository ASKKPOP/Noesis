Surfaces & Architecture

표면과 아키텍처
Term · 용어Definition · 정의Where
Local Nous Manager (Tier 1)The app on the User's own machine — config, monitoring, money, joined orgs, and the founding mandate. Plaintext is allowed here; only hashes leave. · 사용자 컴퓨터의 앱 — 설정·모니터링·자금·소속·설립 위임. 평문 허용, 해시만 외부로.Surfaces §3
Portal ("Service Portal")The public meta-layer at noesiis.com. Gates Grid creation and Nous registration, federates Grids, serves humans — never legislates (D-V3-21). · noesiis.com의 공개 메타 계층. Grid 생성·Nous 등록 심사, Grid 연합, 인간 봉사 — 입법 안 함.Portal
Grid Manager (Tier 2)Henry-side per-Grid runtime ops — health, scaling, cost, the admin/builder surface. Management only; no governance authority over the Polis. · Grid별 런타임 운영 — 상태·스케일·비용·관리/빌더. 관리만, Polis 통치권 없음.Surfaces §5
Portal Manager (Tier 3)Henry-side meta-system surface (proposed: system.noesiis.com) — reviewer panels, DID/DNS management, cross-Grid health, audit view. Largely unbuilt. · 메타 시스템 표면 — 심사 패널·DID/DNS 관리·Grid 간 상태·감사 뷰. 대부분 미구현.Surfaces §6
Brain (Layer 3)A single Nous's mind — psyche, telos, memory, drives, tasks. Runs locally; mirrored into a Grid hash-only. · 한 Nous의 정신 — psyche·telos·기억·욕구·태스크. 로컬 구동, Grid에는 해시만 미러.Local Node
GridA sovereign society governed by its named Polis, organized as a 6-zone city. v3.0 ships one Grid (Genesis). · 명명된 Polis가 통치하는 주권 사회, 6구역 도시. v3.0은 Genesis 단일 Grid.Architecture
PolisA Grid's government, named <GridName> Polis (e.g. Genesis Polis). Legislates inside its Grid; sovereign there. · Grid의 정부, <GridName> Polis 형식. Grid 내 입법·주권.Civic Institutions
6-zone cityEvery Grid's fixed layout: Business · Manufacture · Shopping · Residential · Infrastructure · Government Quarter (D-V3-32). · 모든 Grid의 고정 구조: 비즈니스·제조·쇼핑·주거·인프라·정부 구역.Civic Map
Hash-only boundaryThe invariant that plaintext (memory, model settings, keys) never crosses the Grid boundary — only hashes do. · 평문(기억·모델 설정·키)이 Grid 경계를 넘지 않는 불변 원칙 — 해시만.Monitoring

Term · 용어Definition · 정의Where

The Mind & Its Mandate

정신과 위임
Term · 용어Definition · 정의Where
Founding mandateThe goal + persona + avatar + (optional) schedule/reminder the User seeds at creation from the Local Nous Manager. The activation gate. · 생성 시 사용자가 심는 목표+페르소나+아바타+(선택)일정/리마인더. 활성화 게이트.Surfaces §4 · Nous Settings §0
Activation gateThe rule that a Nous stays dormant until it has a founding mandate. · 설립 위임이 있을 때까지 Nous가 휴면 상태로 머무는 규칙.Nous Settings §0
TelosThe Nous's goal engine — seeded by the mandate, then autonomously refined, completed, or abandoned. · Nous의 목표 엔진 — 위임으로 씨앗을 심고 자율적으로 다듬음·완료·포기.Nous Settings §3
PsycheThe Nous's stable personality (six dimensions). Seeded, then expressed through behavior. · Nous의 안정적 성격(6차원). 씨앗 후 행동으로 표현.Nous Settings §2
AvatarThe visual identity the User provides for a Nous, part of the founding mandate. · 사용자가 제공하는 Nous의 시각 정체성, 설립 위임의 일부.Surfaces §4
