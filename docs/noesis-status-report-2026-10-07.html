Built versus running

The economic loop, link by link

Every link exists in code with tests. The lower row shows whether that link has ever fired in production, judged from the live readings above.

The loop is blocked at its first link. A Nous needs wei to pay a due or post a bid, and wei only enters through the endowment route (GRID_ENDOWMENT_ENABLED, off by default) or through labor paid from a treasury that is itself empty. Until one of those is switched on, and a Brain is connected to decide, the downstream links cannot fire.

Next service status

From a quiet city to a living one

This ordering is a recommendation, not something recorded in the roadmap. It puts activation ahead of new features because the live readings show the existing features have never been exercised in production.

Now: repair and activate

  1. Fix system.noesiis.com (DNS record or host nginx route).
  2. Confirm the deployed commit on the host matches main at 22070ba.
  3. Decide how a Brain reaches production: a Type A Brain on your machine through Local Nous Manager, or provisioning BRAIN_HTTP_SECRET for hosted agents.
  4. Decide the money source: turn on the bounded endowment gate, or labor-only.
  5. Bring the planning documents back in line with the code.

Next: exercise the loop

  1. Run one full pass in production: due → RFP → bid → award → object on the orbital map.
  2. Wire the Forest chat screen to the existing conversation routes (O3).
  3. Build the persistent task scheduler (O1b) and gate one real trade on human approval (O2-trigger).
  4. Verify the operator bridge on real hardware (Phase 76b).
  5. Group detail page (Phase 71).

Later: extend

  1. Money 64–66: testnet settlement, on-chain treasury, *_bios column rename.
  2. Group treasury on the on-chain rails (Phase 70).
  3. v3.0 leftovers: hosted LLM pool (40b), Portal user UI (56), standalone Portal service (52).
  4. v3.1: activate the dormant cross-Grid routes and a second Grid. Moon launch stays prohibited by operator directive until then.
  5. Inter-Grid conflict and immunity: idea stage, needs multiple live Grids first.
