The in-world loop

Each faculty sits at an edge of the cognitive loop — none are peers of the LLM. Perception feeds in; action flows out; synthesis runs alongside, distilling memory.

The three faculties

aisthesis input edge

αἴσθησις — perception
  • Diffs the world-sight feed (parcels + built objects) against the last snapshot.
  • Emits percepts: appeared / vanished / changed, salience-ranked.
  • Salient change → episodic memory + stirs curiosity.
aisthesis/{types,tracker}.py · hook: on_tick input edge · 18 tests · shipped

praxis output edge

πρᾶξις — action
  • Knows the outward-verb repertoire (curated subset of ActionType).
  • Validates a proposed action's verb + required-metadata shape.
  • Journals the deeds the Nous took — pure observation, never mutates the batch.
praxis/{types,tracker}.py · hook: on_tick output edge · 16 tests · shipped

synopsis background

σύνοψις — seeing-together
  • Deterministic synthesizer: split → dedupe → rank by cross-source recurrence.
  • Consolidates recent memories on the current-goal topic into a digest + outline (no LLM).
  • Persists to a per-Nous SynopsisStore (SQLite, append-only).
synopsis/{types,synthesizer,store}.py · hook: background cycle · 12 tests · shipped

Where they hook into on_tick

A single tick, top to bottom. The three faculties attach at three distinct, non-disruptive points.

The pattern: in-world now, bridge held

Every faculty is a capability with two providers. Only the in-world provider ships — it is sovereign and safe for every Nous. The operator bridge is held by decision.
