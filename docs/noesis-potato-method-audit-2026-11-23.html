The Potato Method, applied to Noēsis

Lauren Tan's argument: agents copy whatever the codebase already does, so you make agent output trustworthy by investing in the environment, meaning deterministic checks first, verification second and prose last. This audit measures every layer of that pyramid on this repository, applies the first fixes, and sets the order for the rest.

Noēsis already turns its constitution into code (31 CI gates). It has not done the same for everyday code quality, so copied patterns spread unchecked. One example is 193 hand-copied ID regexes in a dozen shapes that disagree with each other.

Layer 2 · Static analysis

Bugs a linter found the first time it ran

  • A latent crash in the Brain skill sweep fixed: rpc/handler.py catches json.JSONDecodeError, but the module imports json only as _json. A malformed payload_json would raise NameError instead of falling back. Ruff F821 found it.
  • Shadowed methods fixed: hash_state, query_memory, force_telos, _build_refined_telos and _dialogue_driven_goal_set were each defined twice. ASTs compared identical, so the second copies were deleted with no behaviour change.
  • 19 unused imports, 6 dead variables, and undefined names in type hints for the lazily imported anthropic, openai and GridWireClient fixed.
  • mypy strict: 212 errors in 49 files open. Configured, but never run.

Next

Recommended order

  1. Decide whether HEX64 hashes are lowercase-only, then fold the 193 regexes into id-patterns.ts (one named export per DID kind). This needs a decision because it changes what some emitters accept.
  2. Wire getExistenceDid in production so fork manifests stop recording a placeholder.
  3. ESLint flat config with @typescript-eslint: move the ratchet rules into real lint rules with the same messages, and run it in CI.
  4. Replace the allowlist line-count gate with a member-set snapshot.
  5. A feature map of every dashboard and steward route, a gate that keeps it complete, and a Playwright screenshot per route as PR evidence.
  6. Property tests for economy and settlement invariants, and a statechart for Portal → Polis registration.
  7. Automate the outer loop last: agent-merged PRs, per category, only while the revert rate stays low.
