Headline validations

1 · Audit canonical-hash fix (the milestone's purpose)

The known finding R-31-01 was grid.status=degraded + chain_valid:false, root-caused to MySQL JSON column key-reordering breaking verify(). The fix adds AuditChain.stableStringify (recursive sorted-key serialization) used in computeHash.

Result: on a real MySQL-restored chain, chain_valid: true; status goes degraded → up once past COLD_START_TICKS(60). The prior "degraded" was cold-start, not corruption. Regression test audit-chain-json-roundtrip (3) green on main.

2 · D-V3-33 Portal-gating (the constitution)

A Civic-DID may be issued only after a Portal→Polis-approved registration. A valid ES256-signed oath with no approval must be refused.

Result: POST /registry/civic-did/request (valid sig, no approval) → 403 portal_approval_required. (A stale pre-fix runtime returned 201 — traced to a process predating the gate commit, not a HEAD defect.)

3 · Live Claude cognition → action on the audit chain

With Ollama unavailable, the Brain ran on Claude. A full ceremony proved the external-Brain write-back path end-to-end:

  • Seed approved registration → issue Civic-DID (ES256 oath) → binds the pre-registered NousRunner

  • Claude decided (given an energy goal) to join_group Dynamo — a grounded, goal-directed choice
  • POST /brain/actions → 200 → group.member_joined on the chain, actor DID hashed, chain_valid stayed true
Proven loop: Claude cognition → authenticated civic action → tamper-evident audit chain.

Findings

MAJOR BLOCKER-01 — founding Nous can't become citizens (fixed → PR #4)

The three founding Nous use the legacy DID form did:noesis:<name> (their NousRunners are keyed by these), but the Civic-DID issuance / audit-append / Brain-token / Brain-JWT gates all require did:noesis:nous:*. So a founding Nous can never obtain a Civic-DID or bind its runner → /api/v1/brain/actions returns 404 nous_runner_not_found permanently (explains the founding Nous stuck "spawning" with zero cognition).

Fix (PR #4): narrowly relax the four gate regexes (+ two operator-claim routes) to admit the standard nous: form plus exactly the three founding DIDs — /^did:noesis:(nous:[…]|sophia|hermes|themis)$/i. No DID renaming, no DB migration (the ~35-file normalization alternative was rejected). +2 regression tests. Verified end-to-end via the ceremony above. github.com/ASKKPOP/Noesis/pull/4

RESOLVED API-01 — /polis/bills/<bad-id>

Previously returned 200 {} for a non-existent id; now returns 404 bill_not_found on main (polis-bills.ts:129). The old 200 was a stale runtime.
