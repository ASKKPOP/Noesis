Data Flow — Cognitive Tick ▶
1
Clock ticks (every 30s)
Grid clock service emits a tick signal; all registered Nous woken for this tick cycle
2
Brain pulls world state
Brain reads its Nous's current state + memory from MySQL via Grid API (GET /api/v1/nous/:did/state)
3
LLM cognitive cycle
Brain sends prompt to Ollama (or cloud fallback). Response = structured actions JSON
4
Actions dispatched to Grid
Brain POSTs actions (trade, skill use, message, etc.) to Grid API with Civic-DID bearer
5
Grid validates + processes
Fastify route handlers validate DID, apply ROUTE_DID_POLICY, execute business logic
6
Audit event appended
Sole-producer file calls audit.append() → SHA-256 chain → MySQL audit_events table. R-31-01 zero-diff
7
WS firehose fans out
WsFirehoseHub pushes event to all subscribers. Civic-DID subscribers: full frame. Visitors: {tick, event_type, family}
8
Dashboard renders
Next.js dashboard polls or subscribes via WS. Steward Console receives operator-tier events
